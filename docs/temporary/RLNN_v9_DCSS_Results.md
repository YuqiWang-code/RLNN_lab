# v9 · DCSS（密度补偿尺度空间算子）实验记录

日期：2026-11-15。方向出处：`docs/temporary/RLNN_v8_SOTA_Direction.md` §5。
代码：`models/mis_v9_scale.py`（算子）、`models/check_v9_scale.py`（四项校验）、`train_scripts/v9/scale_train.sh`（训练）。
接线：`models/main.py:45` 的 `--arch` 增加 `scale` / `norm`；`models/solvers.py:278` 构造算子；`models/mis_v8_pad.py` 的 `_logits()` 在 `scale` 臂上传入 `self.scale` 缓冲（该引擎调用时 `edge_index is None`）。

## 0. 结论先行

1. **两个臂都输，方向判决为负。** `scale`（特征银行）比冻结 GCN 低 **0.71–0.78**（五个预算几乎恒定）；`norm`（层内 RMS 标定）低 **0.07–0.89**（随预算收窄）。同一配方、同一 1000 图、同一时钟，无一个预算为正。
2. **`scale` 失败于表达力，不是时间**：单步慢 1.67×（0.554 vs 0.33 ms），但差距在 0.05 s 与 1.0 s 上一样大 → 把步数补回来也追不上。它把五层消息传递换成了「多跳计数特征银行 + MLP」，网络不再能组合跳与跳之间的非线性，只剩逐点映射。
3. **`norm` 失败于吞吐，不是表达力**：它保住了层叠，训练追平（−19.40 对 −19.42），但每层多一组 `pow/mean/sqrt`，单步 **0.714 ms**（2.1× 慢），1.0 s 只跑 1347 步对 2887 步。**等步数对照才是判决点**：`norm` 1347 步 → 19.9115，冻结 1310 步 → 19.9450 —— 同样的步数它还**低 0.034**，说明「去掉逐跳衰减」本身没有带来任何单步增益，代价全是额外的。
4. **算子按设计工作过**（唯一的正结果）：`scale` 让解更散（Jaccard 0.085 → 0.048、并集 142.2 → 158.3），**精确重组余量涨 15×**（+0.050 → +0.750）。但分散度是用质量买的（best 19.35 → 17.55），+0.75 补不回 1.8。
5. **次要但重要的副产品**：旧文档 §3-D1 的推论「确定性映射 → 唯一不动点 → 20 粒子同盆地」**被证伪** —— 三个臂都是 20/20 个互不相同的解。版本 A 里要改写成「粒子已经分散，但分散的区域都在同一水位」。
6. 实现没有错：四项校验全绿（一跳计数 = `A@x` 误差 1.9e-06；padded 惰性 6e-08；两条调用路径逐位一致）。

## 1. 算子做了什么（与旧骨干的唯一差别）

旧骨干（`models/models.py`）：对称归一化 `D~^{-1/2}(A+I)D~^{-1/2}`，每层是邻居的**均值**；在 `n=264`、平均度 ~80 的 RB 图上，每跳节点间对比度衰减约 1/9、1/80、1/700。

新算子（`ScaleSpaceGCN(1, hidden, layers, 1, hops=3, tau=2.0)`）：

```
adj = D~^{-1/2}(A+I)D~^{-1/2}
A x = sqrt(d~) * (adj @ (sqrt(d~) * x)) - x        # 反解出「计数」而不是均值
c_k = A^k x                                        # k = 1..3 跳的已选邻居计数
e_k = (c_k - mean_i c_k) / std_i c_k               # 每跳只对真实行标准化
h_i = [w_1 e_1, ..., w_K e_K, x_i, log d_i] -> MLP -> logit
w_k = exp(-tau) tau^k / k!  * gain                 # 热核，tau 与 gain 可学习
```

实测的两个极端（`models/check_v9_scale.py`）：**均值形式**三跳对比度衰减到 0.1001（std 0.014282 → 0.001802 → 0.001430）；**原始计数形式**三跳 std 反而从 2.0 涨到 7145（涨 3576×，最深一跳用纯量级压倒一切）。所以必须每跳标准化。

## 2. 训练（同一配方，只换算子；50 epoch，1000 图，seed 0）

| 臂 | 算子 | 末轮 `valid_obj` | 最好轮 | 说明 |
| --- | --- | --- | --- | --- |
| `gcn` | 五层均值 GCN（对照） | −19.42 | **−19.53**（第 49 轮） | 与冻结骨干 `none_seed0` 同构 |
| `scale` | DCSS 特征银行 + MLP | **−17.78** | −17.78（第 30 轮后平） | 低 1.64 |
| `norm` | 五层 GCN + 每层 RMS 标定 | **−19.40** | −19.44（第 47 轮） | 与 GCN 打平（差 0.02，单种子噪声内） |

→ `scale` 的训练目标比同配方 GCN 低 1.64；`norm` 与 GCN 打平。三臂前 3 轮几乎重合（−17.39 / −17.40），说明起点与优化器一致，差别来自算子。

两条失败模式不同：
- `scale`：单步 0.554 ms（1.67×）、1.0 s 少做 1160 步，但**差距在五个预算上几乎恒定（−0.71~−0.78）** → 时间不够不是原因，策略本身更弱。
- `norm`：单步 0.714 ms（2.1×）、1.0 s 少做 1540 步，**差距随预算单调收窄（−0.89 → −0.07）** → 说明策略本身只差一点点，主要损失在吞吐。

**等步数对照（判决点）**：`norm` 1347 步 → 19.9115；冻结 1310 步 → 19.9450 → **同样步数下 `norm` 低 0.034**。把时钟还给 `norm`（假设它能跑到 2887 步）也补不回这 0.034，只会更小；结论是「去掉逐跳衰减」在这张图族上没有单步增益，代价纯属额外。

## 4. 多样性普查（20 图，seed 1017，K=20，`models/diagnose_v7_census.py`）

| 臂 | distinct | Jaccard 均值 | Hamming 均值 | best | mean | 重组 oracle 增益 | 并集 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 冻结 GCN | 20/20 | 0.0849 | 30.80 | 19.35 | 18.14 | +0.050 | 142.2 |
| `scale`（DCSS） | 20/20 | **0.0476** | 28.87 | 17.55 | 15.83 | **+0.750** | **158.3** |
| `norm` | 20/20 | 0.0800 | — | 19.40 | 18.14 | +0.100 | 145.2 |

三点必须记下来：

1. **「20 个粒子必然是同一个盆地」这个前提是错的。** 两个臂在 20 张图上都是 20/20 个互不相同的解、Jaccard 只有 0.085。旧文档 §3-D1 的推论（「确定性映射 → 唯一不动点 → 20 粒子同盆地」）**与实测不符**，需要在版本 A 里改写成「粒子已经分散，但分散的区域都在同一水位」。
2. **DCSS 确实把解推得更散**（Jaccard 0.085 → 0.048，并集 +16 个节点），且**重组余量涨 15×**（+0.05 → +0.75）。这是本方向唯一被证实有效的一环。
3. 但 DCSS 的 `best` 从 19.35 掉到 17.55、`mean` 从 18.14 掉到 15.83：**换来的分散度是用质量买的**，而重组余量 +0.75 补不回 1.8 的质量差。

## 5. 第二个臂：`--arch norm`（保留层叠的密度补偿）

诊断的落点：DCSS 失败在「把五层消息传递换成单次特征银行 + MLP」，不在「密度补偿」这个想法本身。所以第三个臂保留 `GCN` 的全部结构（五层、隐层 128、残差 `x = act(nei + Wx) + x`），只在每层把聚合结果按 RMS 重新标定：

```python
nei = conv(x, adj)
nei = nei / nei.pow(2).mean(dim=0, keepdim=True).sqrt().clamp_min(1e-3)   # 只有 --arch norm 走这行
```

这与 DCSS 的区别是：**组合能力留着，衰减被去掉**。判据是：同配方 50 epoch，`valid_obj` 追平 −19.4 以上，部署 1.0 s ≥ 19.983。

判决：**训练打平（−19.40 对 −19.42），部署全线为负（1.0 s 19.9115，−0.07）**。原因是每层多一组归约核，单步 0.714 ms（2.1×），1.0 s 只跑 1347 步；而**等步数下还低 0.034**，即单步增益为零。→ 「逐跳能量衰减」不是这个图族的瓶颈，方向到此为止。

## 6. 方向判决

`--arch norm` 的判据是「若只做到与 GCN 打平（无增益），说明能量衰减不是瓶颈，方向到此为止」。实测**比打平还差一点**，所以：

1. **DCSS 方向关闭**。两个臂（特征银行、层内标定）分别死在表达力与吞吐，且互补地说明了同一件事：在 RB[200–300] 这张平均度 ~80 的密图上，「看见更多跳」的信息增益不抵它的代价。这与 G1 感受野剖面的读法一致：骨干的可用深度已经是 2–3 跳，**跳数不是缺的东西**。
2. **唯一可带走的正结果是多样性机制**：`scale` 把重组余量从 +0.05 推到 +0.75，但代价 1.8 个点。若以后有人要做「多样性换重组」，这是现成的量化起点（`models/mis_v9_scale.py` 保留）。
3. **SOTA 结论不变**（`docs/temporary/RLNN_v8_SOTA_Direction.md` §0.5）：无 SOTA。RLSA 在 0.2 s 就拿 19.962、0.65 s 拿 20.073，我们在 1.0 s 是 19.983。
