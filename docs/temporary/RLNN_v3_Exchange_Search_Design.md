# RLNN v3：逐图诊断、平台搜索与动作收益排序

日期：2026-11-08。任务：RB200–300 上的最大独立集。本文依据已完成的 v2 结果确定下一版设计；v3 的收益、用时和训练准入仍需实验确认。

## 1. 研究决策

**v3 以冻结的 RLNN＋规则交换为基座，学习合法中性交换之后的有限搜索收益。** 原 SEGF 不再进入每一步 Bernoulli 搜索；交换结构信息保留，频率表示移到合法解上的动作评分中，作为独立消融。PAVE 的重点从“给立即 +1 的动作排序”转向“选择能打开后续改善路径的中性动作”。

这项取舍直接来自三项结果。

- SEGF 对原 RLNN 的三种子平均差为 −0.00733，对等总更新预算的 RLNN 微调为 −0.03667，固定步数用时约为原模型的 1.93 倍。
- PAVE 验证中的 35 个后备邻域候选，经过规定的后续搜索后都恰好增加 1 个节点，64 对比较全部平局。正式排序头没有训练。
- RLNN 加规则 1→2 的收益为 +0.02033，扩到后备 2→3 后为 +0.05867，平均额外用时约 2.19 ms。收益主要来自打开更多可改进状态。

| 部分 | v3 决定 | 用途 |
| --- | --- | --- |
| 原 RLNN、原 best-energy 记录、A.3 | 保留，冻结权重 | 提供已验证的初始合法解 |
| 规则 1→2 / 后备 2→3 | 保留 | 利用直接、廉价的改善机会 |
| v2 全轨迹双阶分频与动态门控 | 停用 | 现有收益不足以承担逐步开销 |
| tightness、释放关系、兼容性 | 保留并补充 2-tight 信息 | 描述合法动作及其后继状态 |
| PAVE 成对收益监督 | 保留，改变动作与标签 | 预测有限平台搜索的最终增益 |
| 1→1 合法中性交换 | 新主线 | 跨过严格改善邻域的停滞点 |
| anchored 2→1 | 条件扩展实验 | 只有中性邻域覆盖不足时才启用 |
| 频率编码 | 后续独立消融 | 检验是否优于同信息、同规模的普通编码 |
| v1 额外轨迹 Archive | 继续停用 | 局部搜索只保留工作解和最佳合法解 |

## 2. v2 逐图结果说明了什么

### 2.1 统计口径与主结果

固定步数测试为作者提供的同一批 1,000 张图，训练种子 0、1、2，K=20、T=100、A.3、FP16。Mean Size 的标准差是三个种子均值的**样本标准差**。配对统计中的 3,000 条记录是“图 × 训练种子”，不是 3,000 张独立图。

| 方法 | Mean Size，均值±标准差 | ΔSize，相对原 RLNN | 秒/图 | 同一次运行的交换增益 |
| --- | ---: | ---: | ---: | ---: |
| RLNN | 19.51633 ± 0.00907 | 0 | 0.26627 | 0 |
| RLNN 同预算微调 | 19.54567 ± 0.01250 | +0.02933 | 0.23483 | 0 |
| SEGF | 19.50900 ± 0.01153 | −0.00733 | 0.51332 | 0 |
| RLNN＋rule | 19.53667 ± 0.01172 | +0.02033 | 0.26658 | +0.02033 |
| **RLNN＋rule23** | **19.57500 ± 0.00656** | **+0.05867** | **0.26846** | **+0.05867** |
| SEGF＋rule23 | 19.57200 ± 0.00794 | +0.05567 | 0.51553 | +0.06300 |

`rule` 表示最多三轮 1→2；`rule23` 表示每轮优先 1→2，只有没有 1→2 时才找 2→3，**不是联合枚举两个邻域**。同一模型的固定步数后处理对照共享完全相同的起始解。

逐图差值比均值更能说明 SEGF 的行为。

| 配对比较 | Seed 0 Δ | Seed 1 Δ | Seed 2 Δ | 总胜 / 平 / 负 |
| --- | ---: | ---: | ---: | ---: |
| SEGF − RLNN | −0.013 | −0.019 | +0.010 | 401 / 2179 / 420 |
| SEGF − RLNN 微调 | −0.020 | −0.050 | −0.040 | 361 / 2176 / 463 |
| SEGF＋rule23 − RLNN＋rule23 | −0.003 | −0.013 | +0.007 | 406 / 2185 / 409 |

SEGF 相对原 RLNN 的非零变化中，806 条为 ±1，15 条为 ±2，主要是小幅得失相互抵消。对微调基线的损失在三个种子上方向一致；测试前后两个 500 图分组的差分别为 −0.030 和 −0.04333，也没有集中在单一分组。

规则后处理使两种骨干的均值接近。进一步按 SEGF 原始得失分组，在其弱于 RLNN 的 420 条记录中，SEGF 自身的规则修复平均收益为 +0.16905，RLNN 为 +0.01429；在其优于 RLNN 的 401 条记录中，两者分别为 +0.00748、+0.20698。**较弱的一方往往留下更多廉价修复机会。** 因此 SEGF 上稍高的交换增益不能当成频率模块改善了交换能力的证据。

数据来自 [RLNN 测试目录](../../outputs/v2/test_base_seed0/none/per_graph.csv)、[微调测试目录](../../outputs/v2/test_none_seed0/none/per_graph.csv)、[SEGF 测试目录](../../outputs/v2/test_segf_seed0/none/per_graph.csv) 及对应 seed1、seed2。

### 2.2 固定时间下，额外表示挤占了有效搜索

| 0.5 秒预算 | Mean Size，均值±标准差 | Δ，相对同预算 RLNN | 平均实际秒/图 | 同运行交换增益 |
| --- | ---: | ---: | ---: | ---: |
| RLNN | 19.52067 ± 0.01159 | 0 | 0.31569 | 0 |
| RLNN＋rule23 | 19.57133 ± 0.00802 | +0.05067 | 0.31319 | +0.05300 |
| SEGF | 19.38167 ± 0.06673 | −0.13900 | 0.43740 | 0 |
| SEGF＋rule23 | 19.44700 ± 0.03245 | −0.07367 | 0.42672 | +0.10200 |

无后处理时，RLNN 平均执行 99.847 步，98.6% 的图跑满 100 步；SEGF 平均执行 79.664 步，仅 18.7% 跑满。SEGF 在固定步数下已经没有稳定质量优势，固定时间下又损失搜索步数，因而更弱。所有这些组的可行率均为 100%，没有截止超时或空解。

## 3. SEGF 为什么没有提升

### 3.1 识别交换结构，没有自动变成改善解的决策

v2 的状态关系图连接已选节点与只受它阻挡的未选节点。它提供了有用的释放信息，但缺少两层约束。

1. 同一已选节点释放出的多个节点可能互相相邻，释放数量不等于能同时加入的数量。
2. 原 Bernoulli 搜索状态可能整体不可行，局部存在交换结构不等于整个状态可执行一次合法改善。

在 step50，SEGF 每个采样粒子的局部兼容 1→2 数为 1.085，整体可行状态上的合法 1→2 数只有 0.005；step100 分别为 0.900 和 0.035。诊断的 AUC 标签是原始状态上这些局部结构的端点，包含不可行状态。

| Step50 机制量 | 原 RLNN 轨迹 | SEGF 轨迹 |
| --- | ---: | ---: |
| 普通频带范数识别结构端点的 AUC | 0.69128 | 0.71637 |
| 交换频带范数识别结构端点的 AUC | 0.96406 | 0.96993 |
| 翻转概率识别结构端点的 AUC | 0.83170 | 0.80617 |

原 RLNN 没有使用交换分支，事后计算相同交换特征也得到约 0.96 的 AUC。**该 AUC 证明关系可识别，没有证明学到了动作价值。** 标签与释放关系的构造高度重合；更清楚的结构特征也没有转化为更高的翻转概率 AUC。两列来自各自轨迹，不能作为同一状态上的受控因果比较。

而且 v2 交换分支主要围绕 1-tight 节点，规则收益中更大的新增部分却来自 2→3。这要求下一版显式包含 2-tight 节点与加入节点间的兼容性。

### 3.2 监督目标与联合动作之间有间隔

SEGF 沿用一步期望能量及期望翻转数约束，没有直接接受“后续合法解增加了多少”的监督。对于合法极大解上的一个 1→2 交换，移除旧节点的单步能量变化为 +1，两个新节点各自单独加入为 β−1=+0.02，三者联合执行的变化却为 −1。

独立 Bernoulli 参数能够表达确定的联合翻转，但没有显式选取同一个兼容交换的动作结构。增加高频特征仍要通过原有目标自行学会协调移除和加入。当前实验没有证明这条学习路径有效。v3 直接在合法动作上监督后续结果，缩短表示与评价目标之间的距离。

### 3.3 门控主要成为共同开启的稳定缩放

step25–100 的 low 门均值范围为 0.86106–0.86168，high 为 0.80500–0.80528。step100 两路均有超过 99.5% 的门值落在 `[0.7,0.9)`。门控没有表现出明显的阶段切换。

分支也没有消失。step50 的两路残差范数分别约为主干初始表征的 4.04%、5.40%。因此“残差系数归零，模块根本没工作”不符合诊断；更符合现象的是增加了近稳态扰动和传播成本，却没有形成最终质量收益。门值分布不足以推断 Sigmoid 梯度完全饱和。

### 3.4 单种子控制支持简化，尚不能选出新的频率主干

| Seed0 适配器 | Mean Size | 相对同种子 RLNN 微调 |
| --- | ---: | ---: |
| 参数量匹配 MLP | 19.517 | −0.016 |
| MIS 状态统计 | 19.534 | +0.001 |
| 静态一阶分频 | 19.550 | +0.017 |
| 静态双阶分频 | 19.522 | −0.011 |
| 交换统计 | 19.539 | +0.006 |
| 仅高频 | 19.538 | +0.005 |

静态一阶和固定融合优于完整 SEGF，但只有一个种子。它们值得保留为后续探索，不能据此直接替换主干。v3 主实验不继续扩大全轨迹分频组合。

## 4. PAVE 为什么没有排序信号

### 4.1 这是候选价值退化，正式排序网络尚未训练

诊断覆盖同一批 100 张验证图的三个 RLNN 训练种子，共 300 个最终 best-of-20 解。

| 验证候选邻域 | 有动作的解 | 单动作解 | 多动作解 | 动作总数 | 候选对 | 非平局对 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 1→2 | 9 / 300 | 6 | 3 | 14 | 7 | 0 |
| 1→2，否则 2→3 | 18 / 300 | 12 | 6 | 35 | 64 | 0 |

后备邻域的 18 个状态涉及 14 张不同图。最大初始候选数为 11，没有触及 cap=48。35 个动作都完整计算了“首动作＋固定度数补点＋两轮规则继续”，最终收益全部为 +1。

每个成功后续交换都严格增大集合，标签生成又没有 deadline，所以这个结果还说明：这 35 个动作之后没有额外补点，也没有可执行的后续 1→2 / 后备 2→3。**对这批状态，增大候选上限或继续增加严格改善轮数都不能制造排序差异。**

`decision.json` 的 `pave.train=false` 是正确的研究决策。零非平局对意味着成对排序损失没有训练信号，不能将其描述为训练后的 PAVE 网络学不会。

### 4.2 测试收益来自覆盖面，尚未体现排序价值

| 3,000 条图—种子测试记录 | rule | rule23 |
| --- | ---: | ---: |
| 有改善的起始状态 | 57，1.90% | 171，5.70% |
| 初始多候选状态 | 18，0.60% | 62，2.07% |
| 累计 Size 增益 | 61 | 176 |
| 平均增益 | +0.02033 | +0.05867 |
| 执行 1 / 2 / 3 次交换的记录数 | 53 / 4 / 0 | 166 / 5 / 0 |
| 相对共享起始解的平均额外耗时 | 0.313 ms | 2.191 ms |

在全部 3,000 条记录上，1→2 的 canonical rule、覆盖度 heuristic、random 得到的 **Size 逐图完全相同**。后两者仅分别在 3、9 条记录上返回了不同节点集合。

后备 2→3 新增 114 个起始可改进状态，贡献额外总增益 115。其中 seed2 的 `idx_809` 从 21 到 23，其他新增状态均 +1。原本有 1→2 的状态没有进一步获益。所有已记录的规则路径都满足“Size 增益＝交换次数”，补点未额外加点，也没有用满三轮。

因此 v3 先解决**没有可达改善路径**的问题，再研究如何排序。仅扩大价值 MLP、增加零差异标签或延长旧邻域的严格下降过程，缺少依据。

### 4.3 仍有空间，但在旧候选集合之外

KaMIS 在 seed0 的 100 张验证图上比 RLNN 高 0.55，比当前后备邻域的候选 oracle 高 0.51。它改善的 52 张图中，48 张没有当前后备动作。当前局部停滞并不意味着接近最大独立集。

另一个尚未覆盖的空间是同时存在的 2→3 动作。v2 遇到 1→2 就跳过 2→3，验证中那 9 个有 1→2 的状态没有比较两类动作的联合集合。v3 先在验证集做一次联合邻域普查，区分“后备策略遗漏”与“必须离开严格改善邻域”。

数据与实现见 [seed0 普查](../../outputs/v2/diagnostics_exchange/opportunities.csv)、[seed1 普查](../../outputs/v2/diagnostics_exchange_seed1/opportunities.csv)、[seed2 普查](../../outputs/v2/diagnostics_exchange_seed2/opportunities.csv)、[KaMIS 逐图结果](../../outputs/v2/diagnostics_kamis/per_graph.csv)、[交换实现](../../models/mis_v2_exchange.py)、[训练准入](../../outputs/v2/decision.json)。

## 5. v3 搜索与监督的具体设计

### 5.1 求解流程

```text
冻结 RLNN，K=20、T=100
          ↓
原 best-energy 记录 → A.3 → 合法解 S
          ↓
v2 rule23（最多三轮）→ 工作解 W、最佳合法解 S_best
          ↓
生成 W 上的合法 1→1 候选，最多 32 个
          ↓
规则 / 统计 PAVE / 频率 PAVE 选择一个首动作
          ↓
固定 H=2 的中性动作与规则继续 → 新工作解
          ↓
更新 S_best；最多 8 个外层轮或达到时间截止
          ↓
返回 S_best
```

新模块只在解码后的合法解上运行。每次决策的候选共享同一个工作解，不在 20 条轨迹、100 步中重复计算频带。工作解允许在相同 Size 的合法集合间移动；输出保持当前最大的合法集合。

主基座先固定原 RLNN，便于与 v2 的 19.57500 直接衔接。另补做“RLNN 微调＋相同后处理”对照，通过验证集确定是否更换部署基座；排序方法比较始终使用同一套冻结权重和起始解。

### 5.2 主动作是合法 1→1，先改变阻挡关系

令合法解为 S，未选节点的 tightness 为 \(n_v=|N(v)\cap S|\)。对每个 \(n_v=1\) 的节点 v，设其唯一阻挡节点为 u，定义

\[
a_v=(\{u\},\{v\}),\qquad S_v=(S\setminus\{u\})\cup\{v\}.
\]

该动作保持可行和基数，可能改变其他节点的 tightness，打开后续 1→2 / 2→3。被移出的 u 与新插入的 v 相邻，普通补点不会立即把 u 加回来。

若起点确实已没有任何 1→2 和 2→3，那么单次 1→1 后再做一次 1→2，其净变化仍落在旧的 1→2 或 2→3 邻域，不会凭空带来改进。更有价值的路径是 1→1 后接 2→3，或再经过一次中性移动，触及原起点的更大联合交换。这也是 H=2 和后续 2→3 都需保留的原因。

候选默认最多 32 个。少于 32 个时全部使用；否则取覆盖度规则最优的 16 个，再从其余动作按固定随机优先序取 16 个。所有排序对照使用相同候选池。记录完整候选数、保留数，以及普查中完整池与截断池的 oracle 差。

沿用 v2 覆盖度思想，候选启发式按新增节点在未选节点中的邻域覆盖量升序，再按释放规模降序、固定优先序打破平局。另设固定随机选择和原始度数选择作为廉价对照；验证集确定最强规则后冻结。

### 5.3 后续搜索固定，训练和部署执行同一个算子

定义 `Repair(S)` 为按原始度数固定顺序补点，然后最多执行四次 rule23。合法性、候选上限 48、后备顺序均沿用 v2。到达四次上限时标记“本段未确认停滞”，不得把它计为局部最优。

H=1 的分支执行给定 1→1，再执行 `Repair`。H=2 在此基础上继续一段。

- 若仍有严格改善动作，第二段继续 `Repair`。
- 若没有严格改善动作，按冻结的覆盖度规则选另一个 1→1，再执行 `Repair`。
- 没有可用动作时提前结束。

禁止第二段立即撤销前一个中性动作；外层也保留最近两次中性动作的反向禁忌。历史禁忌只过滤外层首动作，候选分支内部只禁止撤销该分支的首动作，不继承更早的禁忌；反向禁忌不限制严格改善交换。因此给定合法首动作后的收益仅依赖 S、a 和固定继续规则，评分器不需要推断未输入的历史。候选和规则继续共享固定节点优先序，避免把不同随机运气当成首动作价值差。默认 H=2，H=1 是必要的深度对照。

首动作之后的第二段使用固定规则，**不递归调用价值网络**。推理时对选中的首动作执行同一个 H 段算子，H 段完成即返回工作解和最佳解，不自动追加规则搜索。离线标签的分支都从相同状态开始，不改变外层历史；部署只提交实际执行分支的中性动作历史。

每个外层轮优先处理剩余严格改善：若初始三轮规则或上一宏动作之后仍有严格改善，本轮只执行一次 `Repair`；否则选择并执行一个 H 段中性宏动作。两种情况各消耗一个外层轮，总上限为 8，不在计数之外追加搜索。整个过程同时受总时间截止约束。

### 5.4 标签是后续合法解增益

在同一图、同一合法工作解 S 上，先按外层禁忌得到候选池，再枚举候选 a 的完整有限继续过程，定义

\[
U(a;S)=\max_{S'\in\operatorname{Rollout}_H(S,a)}|S'|-|S|.
\]

初始 S 也计入过程最佳值，所以 U≥0。1→1 主线本身不降低基数，标签直接描述真实的改善量。保持动作可行性和统一后续预算，不使用能量下降、结构端点 AUC 或任意单点翻转作为替代标签。

训练时每个状态最多采样 64 个非平局候选对；先对状态内取均值，再对状态取均值。

\[
\mathcal L=\frac{1}{|\mathcal S_+|}\sum_{S\in\mathcal S_+}
\frac{1}{|\mathcal P_S|}\sum_{(a,b):U(a)>U(b)}
\operatorname{softplus}\bigl(s_\theta(S,b)-s_\theta(S,a)\bigr).
\]

平局状态仍保留在数据和全状态评价中，只是不贡献这个排序损失。候选多的状态不因拥有更多配对而支配训练。若 H=2 标签在不同固定优先序下很不稳定，先在同一批验证状态用三个优先序量化稳定性，再决定是否扩充训练重复；不直接用单次排序精度掩盖噪声。

### 5.5 anchored 2→1 是有条件的扩展

当 1→1 的 oracle 覆盖仍不足时，可对 n_v=2 的未选节点 v，移除其两个阻挡节点再插入 v，得到合法的 2→1 扰动。

这一步有一个确定的退化：刚移除的两个节点彼此不相邻，且在新状态中的唯一阻挡节点都是 v，因而天然构成恢复原解的 1→2。直接交给原 rule23 会大量立即撤销扰动。

扩展实验因此在首段继续中固定保留 v，过滤所有移除 v 的规则动作。该段结束后解除固定，完成规定的继续并与 incumbent 比较。若宏动作结束时工作解小于过程中保存的最佳解，则恢复该最佳解；失败分支不提交新增禁忌，沿用宏动作前的外层历史。每次新宏动作都从 incumbent 大小的工作解出发，避免把恢复此前损失误计为改善当前最好解。标签仍取过程中的最佳 Size，另记复原率、回退前终点低于起始解的比例、正增益覆盖。训练和推理使用相同约束。

这项实验单独报告，不与 1→1 的即时收益混在一起解释排序质量。需要分别报告同一动作类型内部的 oracle 差和模型 regret，避免网络仅靠识别动作类型获得漂亮的整体准确率。

## 6. 模型结构与训练数据

### 6.1 PAVE-Stats 是第一版默认模型

先使用不超过 24 维的可解释动作统计，MLP 为 `input → 64 → 32 → 1`，SiLU 激活。特征全部在首动作执行前计算。

- 移除/加入节点的原始度数、tightness、释放的 1-tight / 2-tight 节点数。
- 受影响区域中未选节点的邻域覆盖、共同覆盖，以及已有节点间的兼容对数量。
- 对假设执行首动作后的 tightness 做局部更新，统计新增/减少的 0-tight、1-tight、2-tight 节点，以及可行 1→2 候选数。只计算局部结构变化，不运行标签继续过程。
- 当前 Size/N、剩余外层决策比例；候选生成和特征计算共同遵守相同禁忌上下文。

统计和兼容计数用已有 bitset 邻接完成。推理默认在 CPU 一次批量评分整个候选池，避免每个候选触发一次 GPU 同步。其开销必须包含在总时间内。

### 6.2 频率只作为动作编码消融

基础统计头有收益后，再比较两种同宽度的节点编码。每个合法状态只计算一次节点表示，再池化给所有候选。

节点输入取

\[
F_i=[x_i,\min(n_i,3)/3,\log(1+d_i),\mathbf1(n_i=1,x_i=0),
\mathbf1(n_i=2,x_i=0),\log(1+r_{1i}),\log(1+r_{2i}),\log(1+c_i)].
\]

其中 r₁、r₂ 为邻接的未选 1-tight / 2-tight 节点数，c 为已选节点可释放的 1-tight 集合中兼容节点对的数量，未选节点的 c=0。它补上“释放很多但互不兼容”的信息。

普通消息对照使用 \([F,MF]\)，其中 \(M=D^{-1}A\)。一阶频率使用

\[
L=(F+MF)/2,\qquad H=F-L.
\]

两种编码均为两个 `8 → 32 → 32` 的 SiLU 分支，输出拼接为 64 维，不使用动态门控、不使用双阶传播。孤立点传播等于自身。

对动作 (u,v)，拼接 u、v 的表示，以及受影响区域 \(N(u)\cup N(v)\) 的 mean/max 池化，再拼接相同的动作统计，使用 `input → 64 → 1` 打分。普通消息与频率模型使用相同输入信息、参数量和邻居传播次数。`[L,H]` 与 `[F,MF]` 可线性互相恢复，因此这项比较检验的是分支参数化和归纳偏置，不能宣称频率凭空增加了信息。

只有一阶频率在三种子上优于普通消息对照，才加交换关系频带。扩展关系图同时连接 1-tight 和 2-tight 未选节点及其已选阻挡点，每条关联按该未选节点的 tightness 加权为 1/n；使用一阶 `F − D_R⁻¹RF`，空关系行取零。该扩展必须配一个同宽度的原始关系聚合对照，才能区分关系信息收益和频带参数化收益。

### 6.3 数据只围绕部署状态扩充

首轮使用既有 1,000 张训练图、100 张验证图，不从 1,000 张测试图生成标签。

默认训练起点由固定的原 RLNN seed0 权重和两个搜索随机流生成，每个起点先做规则改善。每个起点最多保留起始状态和三个规则平台搜索状态，总上限约 8,000 个状态。不同候选、状态、搜索种子都随原图归属同一个数据 split。

验证首先保留三个原 RLNN 训练种子对应的 300 个最终起点，再加入按部署流程访问的中间状态；两类分别报告，不能用大量早期易解状态稀释最终停滞状态的难度。

排序头种子 0、1、2共享训练数据，只改变头的初始化与批顺序。训练 Adam、lr=1e-3、最多 30 epoch，每批 32 个状态，按全状态验证收益选择 checkpoint。若加入节点编码，首轮 lr=3e-4，其余状态、配对、训练轮数及选择指标保持一致。原 RLNN 不参与反向传播。

首轮模型能超过规则后，追加一轮由已学策略访问的训练状态，混入原规则状态重新训练。该项作为分布适配消融，不把整个数据管线变成持续在线训练。

## 7. 先判断有没有学习空间

### 7.1 准入量必须在全部部署状态上计算

对每个状态，令空动作/停止的收益为 0。除了非平局比例，必须计算

\[
\mathrm{OracleGap}=\mathbb E_S[\max_a U(a;S)-U(a_{\rm strongest\ rule};S)],
\]

以及正增益覆盖 \(P(\max_aU(a)>0)\)、候选回到起始集合的比例、截断池对完整池的 oracle 损失。没有候选、单候选、全平局状态都计入分母。

初轮研究准入采用可执行的工作标准：训练集至少 100 个非平局状态，来自至少 50 张不同训练图；验证最终起点上至少 10 张不同图出现非平局，且 oracle 对验证集最强廉价规则的全状态平均优势至少 +0.03。它们是控制研究投入的门槛，不是统计显著性的替代。

未满足时按证据采取行动。

| 观察结果 | 下一步 |
| --- | --- |
| 旧后备邻域无信号，联合 1→2∪2→3 有实质 oracle 差 | 保留联合邻域为更便宜的候选方案，先比较规则收益 |
| 1→1 的 H=1 平局多，H=2 出现 oracle 差 | 使用 H=2 生成正式标签 |
| 1→1 的 H=2 仍几乎无正增益覆盖 | 小规模诊断 anchored 2→1 |
| oracle 有收益，但与最强规则几乎相同 | 采用规则平台搜索，停止对应神经排序训练 |
| oracle 明显优于规则，但模型追不上 | 检查特征、状态分布和标签稳定性，先补统计或分布适配 |
| 统计头已超过规则 | 再做普通消息 / 一阶频率消融 |

### 7.2 模型评价直接对齐选择后果

主验证量是所有部署状态上的“模型所选动作实际 U − 最强规则所选动作实际 U”。同时报告模型对 oracle 的 regret、正收益命中率、全部状态的最终 Size。

非平局状态上的 pair accuracy、Top-1、Spearman 作为辅助诊断，必须同时给出覆盖率。全平局状态的 Top-1 trivially 为 100%，不能用来证明学会了排序。

频率机制在同一批合法状态、相同候选和标签上比较普通消息与频率模型的 regret；再统计推理中真正选中的动作改善率和后续收益。原来的 motif 端点 AUC 不再承担质量机制证据。

## 8. 消融方案与实验顺序

### 8.1 第一阶段：动作与标签普查，不训练网络

| ID | 候选 / 继续 | 要回答的问题 |
| --- | --- | --- |
| D0 | v2 rule23 后备、最多三轮 | 复用既有参照 |
| D1 | 完整 1→2∪2→3 首动作，后续相同 | 后备策略是否漏掉有价值的动作 |
| D2 | 1→1，H=1 | 单次中性移动能打开多少改善 |
| D3 | 1→1，H=2 | 再走一次平台动作是否产生排序差 |
| D4 | D3＋anchored 2→1，仅在 D3 覆盖不足时 | 受控下降是否增加值得学习的机会 |

D0/D1 共用原始 RLNN＋A.3 起点，均计算首动作加后续两轮的价值，保持与 v2 相同的继续深度。D1 必须在原始起点上联合枚举，才能看到“存在 1→2 时被后备顺序跳过的 2→3”。D2–D4 共用相同规则处理后的停止解，另保留运行到规则上限而未确认停滞的状态计数，不混入平台动作普查。

每个相应起点报告 random、degree、coverage 和候选 oracle；oracle 只作诊断上界。完整候选普查用于量化 cap=32 的损失，正式标签按部署候选池生成。

### 8.2 第二阶段：主方法比较

| ID | 配置 | 与谁比较 |
| --- | --- | --- |
| B0 | 冻结 RLNN | 原始质量与耗时 |
| B1 | RLNN＋v2 rule23 | 已确认的廉价收益 |
| B2 | RLNN 微调＋相同规则与平台后处理 | 基座质量是否影响结论 |
| N0 | B1＋1→1 平台搜索，随机选首动作 | 搜索空间扩展本身的收益 |
| N1 | B1＋1→1 平台搜索，验证集最强规则 | 神经排序必须超过的主要对照 |
| P0 | N1 相同候选与继续，统计 PAVE 选首动作 | 学习排序的净贡献 |
| P1 | P0 的普通消息编码 | 节点表示与参数规模的贡献 |
| P2 | P0 的一阶频率编码 | 相同信息量下的频率参数化贡献 |

B0/B1 的固定步数质量可复用已保存解；新的规范计时重新运行。B2 先做验证和规则后处理，选择基座后 N0–P2 共用同一个基座，避免把换骨干的收益算进排序。只有 P0 超过 N1 才训练 P1/P2；只有 P2 超过 P1 才加交换关系频带。

主对照均使用三个匹配组合 `(backbone_seed, head_seed)=(0,0),(1,1),(2,2)`，规则组使用相同 backbone seed。它反映组合方法的种子变化；另在验证集固定 backbone_seed=0 比较三个 head seed，分开观察排序头的训练波动。

### 8.3 第三阶段：只围绕已有效的部分消融

| 变化 | 固定的其他条件 | 判据 |
| --- | --- | --- |
| H=1 / H=2 | 同候选池、同规则、同评分器类型，各自标签训练 | 增加继续深度的收益是否抵消耗时 |
| 1→1 / 加 anchored 2→1 | 相同总预算，分别报告动作类型 | 是否扩大正收益覆盖 |
| 起始终态数据 / 加规则中间态 / 加一轮策略中间态 | 同训练状态数、同更新预算 | 是否缓解部署状态偏移 |
| 统计 / 普通消息 / 一阶频率 | 同标签、同候选；后两者同参数量 | 频率是否有独立贡献 |
| 固定候选32 / 全候选 | 小规模验证，其余相同 | 截断是否已经限制上限 |

不做无目标的全组合网格。频率失败时保留有效的统计头；统计头也没有超过最强规则时，保留规则平台搜索这一结果。

## 9. 测试、产物与实施范围

### 9.1 两种评价协议

**固定工作量**：K=20、T=100、同一初始合法解、初始 v2 rule23 最多3轮、候选 cap32、严格交换 cap48、Repair 最多4轮、H=2、最多8个外层轮（规则补段也计入）。该协议区分初始解、规则扩邻域和排序的贡献。

**固定总时间**：主预算 0.5 秒，必要时补 1.0 秒观察收益—时间曲线。验证与测试统一 FP16 的 RLNN 推理，排序网络 FP32。搜索、A.3、图/特征构造、候选生成、CPU/GPU 往返、评分、继续搜索、可行性检查均计时。

0.5 秒预算初始预留 50 ms 给后处理；仅在验证集比较 20/50/100 ms，选定后对所有平台搜索排序组使用相同预留。平台组保留 T=100 上限，预算余量可用于后处理，记录实际搜索步数和外层决策数。另设充分使用预算的强对照：纯 RLNN 取消 T=100 上限、持续搜索至截止；RLNN＋rule23 只预留规则所需时间，其余用于增加搜索步数。新方法需要超过这些强对照，才能认定在等时间下占优。保留 T=100 的结果同时用于衔接 v2 和分析后处理贡献。

训练任务可以同卡并行；**正式单图延迟评测每张 GPU 同时只跑一个任务**，两卡运行不同组，CPU 核也隔离分配。可先缓存同一基座的逐图起始解供质量配对；端到端总耗时必须在完整求解流程重新测，不能把缓存读取当成搜索成本。

### 9.4 计算安排与预计用时

当前两张 RTX 5090 可用于独立单卡任务。首轮标签计算主要是 CPU bitset 搜索，优先并行图任务，初始 24 个 CPU worker，再按实测吞吐调整；GPU 用于起始解生成和模型训练。CPU 阶段不以显存占满作为效率目标。

| 阶段 | 初步墙钟估计 | 调整依据 |
| --- | --- | --- |
| 100验证图×3基座种子的动作普查 | 15–40 分钟 | 实测每状态候选和继续时间 |
| 训练图起始解、状态与标签 | 30–120 分钟 | 先用50图估计，按实际状态数外推 |

| 普通消息/频率三种子，仅准入后 | 20–60 分钟 | 节点编码吞吐 |
| 主矩阵1000图三种子，固定工作量＋0.5秒 | 2–4 小时 | 最终组数，两卡并行且各卡单任务计时 |

## 10. 已知限制与文献定位

v2 频率实验是每组 6,000 次更新的预训练适配，不是所有结构的充分训练比较。SEGF 第一轮冻结骨干，其三个最终 checkpoint 来自第1/1/2轮；RLNN 微调来自第2/3/2轮。两者总更新预算相同，骨干更新量不同。FP32 验证选择 checkpoint、FP16 正式测试也带来路径差异。因此现有结果足以停用当前高开销结构，尚不能否定频率信息本身。

频率机制诊断只覆盖一个训练种子、100张验证图、前4个粒子；额外解码了多个阶段并累计最佳解，不能用其末点代替正式 final-only 结果。两组机制曲线的运行负载不同，不能比较曲线中的时间。成对强制翻转探针仅为 baseline 的8图16动作、SEGF的6图12动作；SEGF Spearman=−0.1396 的样本量不足以推断普遍机制。

PAVE 的零信号结论限定于已普查的验证终态、后备动作集合及规定继续策略，不能外推到未普查的训练图、粒子解或更大的邻域。测试后续每轮没有记录完整候选数，不能声称所有阶段均未截断。v2 的 greedy extension 是固定原始度数顺序，不是动态残余度贪心。

KaMIS 的内部配置为1秒，实测端到端平均4.114秒，当前只用作质量参考。新方案不能据此声称已经达到可在0.5秒内获得的上界。

严格交换、平台移动和扰动局部搜索已有明确先例。Andrade、Resende、Werneck 的 [Fast Local Search for the Maximum Independent Set Problem](https://mauricio.resende.info/doc/indepset-ls2010.pdf) 讨论了 1→2、2→3 与保持基数的交换序列；它支持本项目从单调改善扩到平台搜索的选择。Dahlum 等的 [Accelerating Local Search for the Maximum Independent Set Problem](https://arxiv.org/abs/1602.01659) 强调了快速局部搜索及在线处理的重要性。v3 的研究假设落在**同一 RLNN 合法起点上的有限继续收益学习，以及这种评分能否在严格总预算下超过强规则**。一阶分频、MLP 排序、1→1 和 2→1 操作本身都不单独构成创新结论。
