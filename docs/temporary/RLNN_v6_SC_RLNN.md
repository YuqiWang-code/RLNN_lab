# v6 SC-RLNN

把状态感知的邻居与自身混合放进 RLNN 骨干，用跨层差分读出预测翻转概率。搜索仍使用逐轨迹能量档案与 A.3 解码，后处理使用 v3 已冻结的 PAVE Stats H1。

## 模型

- 每层从自身投影 (S) 与归一化邻居投影 (M) 构造 ((S+M)/2) 和 ((S-M)/2)，用节点状态门控负号分量。各层只执行一次骨干 SpMM。采样评测从能量计算复用 (Ax)，构图时预计算度数相关特征。
- 输入为当前选点、邻居占用比例、解析翻转能量、归一化对数度与节点相对邻域的对数度差。沿用 B 的 5 层、128 宽度。两带增益用 (1+\tanh(\alpha))，初始 `alpha` 分别为 0.10 和 −0.10，使邻居投影从第一步即可收到梯度。
- 读出从第 1、2、5 层取得 (H_1-H_2)、(H_2-H_5) 和 (H_5)，并加上输入状态的线性读出。层间差分的作用由读出消融检验。由于两路投影独立且层间包含非线性，频带名称表示结构上的和差混合，严格谱响应需要共享投影等附加条件。
- 训练保留仓库的 Erdős 能量和期望翻转数约束。极化项用两个端点已选邻居数均不超过 1 的无向边，奖励下一步选点概率差异的平方。极化权重 0.03，跨层表征余弦平方权重 0.01。两项均按训练批次的图数或节点数归一。

## 对照与筛选

| 实验组 | 配置 |
| --- | --- |
| B | 原 GCN |
| v5 对照 | DAFR-Lite |
| `v6_lowonly` | 每层只用和分量，保留五维输入与跨层读出 |
| `v6_noscatter` | 动态和差混合，读出仅用最后一层与输入 |
| `v6_noanti` | 去掉度差输入和极化奖励 |
| `v6_full` | 完整模型 |

训练种子 42、123、999 分别配对 B/PAVE 的历史种子 0、1、2。v6 各组使用同一训练协议，从随机初始化开始，用相应 B 生成匹配状态。首轮每个种子跑 1 个 epoch、1,000 张训练图、graph batch 8、state batch 64；若通过筛选，正式消融统一跑 3 个 epoch。

RTX 5090 独占计时。验证集 100 张图，固定 K20/T100 分别比较 A.3 和 A.3 + PAVE；0.5s/1.0s 使用连续搜索 + PAVE。CUDA Graph 对照采用相同执行模式。固定 100 步在 FP16、FP32 下的速度比均须 ≤1.08，1.0s 的平均步数至少 250。固定步数裸解码均值须 >19.62，三个种子的 PAVE 均须超过各自 B 且 >19.69。固定预算 + PAVE 分别要求 >19.70 和 >19.85，并高于相同协议的 B。通过验证筛选后使用 1,000 张官方留出测试图。

在训练后的验证轨迹上记录高和中带 logit 二阶矩、逐层归一化狄利克雷能量，以及 PAVE 后对 B 的配对大小差。高带 logit 二阶矩的门槛为 0.01，第五层能量比的门槛为 0.25。用固定步数结果分开判断骨干效果与墙钟限制。
