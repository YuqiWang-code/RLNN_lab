# 当前想法

## v000_baseline

目标是建立可复现的 NExCO 基线，覆盖训练、验证、测试、数值整理和版本归档。

实验顺序：准备 RTX 5090 训练环境和缺失数据，使用小规模 TSP 跑通流程，再扩大问题规模并评估 CVRP 与 MIS。先确定独立的训练、验证、测试划分，记录采样次数、rewrite 参数、本地搜索预算、时间和显存。

后续可在稠密 TSP 上比较当前 GNN 与 Transformer。比较时使用相同数据和推理预算，分别观察目标值、gap、耗时和显存。其他方向在基线完成后登记。

已完成或搁置的想法移动至 `docs/已归档文件/`，保留日期、实验版本、结论和相关结果位置。
