## 回本阈值（E2 唯一要回答的数）

若 N 臂共用一次前向，每臂可保住 810/c 步（c = batch-N 每步毫秒 / batch-1 每步毫秒）。令净收益 ≥0：**N=3 需 c ≤ 1.99×**（配对模型宽松至 2.36×），**N=2 需 c ≤ 1.60×**（宽松至 1.79×）。A0 的 1.264 ms/step 是 batch=1，GPU 在 batch=1 严重空闲，c 落在 1.3–2.0 完全可能。

## 建议

1. **不要**按 808/N 步切分做并行臂——两套独立罚项模型都判亏。
2. **E2** 只测 batch∈{1,2,3,4} 的 ms/step：c(batch3) ≤1.99× ⇒ 三点并行可试（每臂 ~407 步，净 +0.01~+0.02，须实测确认）；c ≥2.4× ⇒ 方差路线关闭。
3. 并行若被否，+0.008~+0.010 的缺口只能走 E3；注意步长曲线在 810 之上已明显饱和（实测 1000→3000 步仅 +0.058），所以 E3 的提速收益必须实测，不能靠对数外推（外推 1200 步给 +0.05 属乐观上界）。
