# RLNN 结构补偿 v2 结果

**No-go，且 v1 的 +0.090 未复现。** 把度数通道从"逐层残差"换成"读出端一次广播加"（`degree_out`）后，三个搜索种子下 T100＋PAVE 的配对 ΔSize 只有 **+0.0133**，95% CI [−0.040, +0.063]，20 胜 64 平 16 负。`all_out`（再加 softplus 尺度的增益残差）与 `degree_out` **逐位相同**——增益通道又一次完全失效。

## 本轮改动

| 项目 | v1 | v2 |
| --- | --- | --- |
| 度数注入 | `degree`：每层残差流各加一次（5 次） | 增加 `degree_out`：`φ(deg) @ w` 加到翻转 logits（1 次广播加），静态量按图缓存 |
| 增益 | `gain`：`tanh(γ)` 门 | 增加 `all_out`：`softplus(scale)` 可学正尺度 ＋ MLP 末层零初始化 |
| 统计功效 | 每图 1 个搜索种子 | **3 个搜索种子**（1017/1019/1021），图内先平均再按图 bootstrap |
| 输出 | `outputs/structure_v1` | `outputs/structure_v2`（`OUT_V2` 可切换） |

## 结果

T100，五臂同进程交错，FP32＋CUDA Graph，100 图 × 3 搜索种子：

| 臂 | 裸 A.3 | Δ裸 | ＋PAVE | ΔPAVE 及 95% CI | 胜/平/负 | 每解耗时 | 相对 B |
| --- | ---: | ---: | ---: | --- | --- | ---: | ---: |
| `baseline` | 19.480 | 0 | 19.580 | 0 | — | 123.7 ms | 1.000 |
| `degree_out` | 19.493 | +0.013 | 19.593 | **+0.013 [−0.040, +0.063]** | 20/64/16 | 137.8 ms | 1.114 |

## 三条结论

1. **v1 的 +0.090 是单种子的波动。** 同样信息、更便宜的注入方式在 3 个种子下只有 +0.013，且胜平负 20:16 接近对称。v1 的 19:11 在 n=100、每图 1 种子时对应 SE≈0.05，本来就是 1.8σ。
2. **增益通道两次都失效。** 换成可学的正尺度（`softplus`，初值 1）与零初始化末层后，`all_out` 与 `degree_out` 的输出完全一致，说明残差本身≈0——问题不在门幅的参化，而在这条特征对 Erdős 目标的梯度太小。
3. **读出端一次广播加仍要 +11%。** 单看算子它很小，但基线每步已是十几个小 kernel 的发射受限状态，多一个 kernel 就按它的发射成本计费。**在这个基线里，"每步多一个算子" 本身就是不合格的。**

## 判决与建议

两项门槛都没过（`fixed` 的 CI 跨零、`speed` 1.11×），`budget` 未跑。按"未复现即归档"的规则，结构补偿这条线在**当前注入形态**下也走到尽头：

- 逐层 / 读出端 / 门控三种形态，信息量相同，效果都在 +0.01–+0.09 且不可复现；
- 增益特征无论怎么参化都不动；
- 任何每步新增算子都过不了速度门。

仍然没被排除的一条（一步之遥但成本另算）：把度数项**折进现有 `final_project` 的权重**（拼接后同一个 `Linear`，零新增 kernel），代价是要改热启动的 shape 处理。如果要做，建议先确认"零效应"不是注入位置造成的——但目前三个位置都是零，证据指向信息本身没有增量。
