# v4 频域参考：方法与源码

阅读依据为本地论文正文及 `reference_methods/*/upstream.json` 对应源码快照，日期2026-11-09。正式论文与全部16项下载入口见[文献索引](../参考文献/文献索引.md)。

## GRACE：已有专家融合，但任务状态不同

论文第4节的低通专家采用 GCN；高通专家先计算 `XW − H_low`，经缩放、LayerNorm及注意力产生输出。门控将原特征、邻居差异、特征标准差和度数结合，用两专家 softmax 融合。[论文页](https://proceedings.neurips.cc/paper_files/paper/2025/hash/eb154abcbfa13d23f01ad3e091e92b08-Abstract-Conference.html)

对应 [models.py](../../reference_methods/GRACE/source/models.py) 的 `LowPassExtractor`、`HighPassExpert`、`Gating` 和 `MOE`。代码使用有符号 `AX−X`，论文门控公式描述绝对差；`Gating._x_cat` 只在第一次前向计算并缓存。该实现针对固定节点特征，不能直接用于每步变化的 RLNN 候选状态。高通路径经过注意力和非线性后也不再是一个固定线性高通算子。

可借鉴的是专家职责和局部条件。v4 的区别应由动态 MIS 状态、独立注入门控、翻转决策及最终解质量对照建立；少样本支持集/查询集校准不对应当前任务。

## WaveGC：严格小波构造与实现成本

论文第3节将 Chebyshev 基变换为 `(1−T_k(λ−1))/2`：偶阶构造零直流的小波，奇阶构造补充直流的 scaling；系数和尺度由特征值编码预测，随后在小波坐标上应用共享 MLP。[论文页](https://proceedings.mlr.press/v267/liu25y.html)

对应 [wave_generator.py](../../reference_methods/WaveGC/source/WaveGC_node/graphgps/layer/wave_generator.py) 的 `gen_base` 和 `forward`，以及 [wave_layer.py](../../reference_methods/WaveGC/source/WaveGC_node/graphgps/layer/wave_layer.py)。源码显式使用特征值和特征向量，并支持多尺度及 tight-frame 归一化。v4 的 `P²Z、PZ−P²Z、Z−PZ` 是低阶传播差分，不能称为直接复现 WaveGC；其适用理由是动态图搜索中的成本控制，独立效果由同信息消息对照检验。

## HeroFilter：谱相关 patch，而非双频门控

论文第3–4节指出异配度与最佳谱响应不存在统一单调关系。方法用 `U g(Λ) Uᵀ` 构造相关性，选取每个节点的 top-p patch，再用 patch 轴和特征轴 MLP-Mixer 聚合。[论文页](https://proceedings.neurips.cc/paper_files/paper/2025/hash/5d570ed1708bbe19cb60f7a7aff60575-Abstract-Conference.html)

对应 [HeroFilter.py](../../reference_methods/HeroFilter/source/src/HeroFilter.py) 的 `Patcher`、`PatchMixer`、`FeatureMixer`。`HeroFilter_fast` 使用预先构造的邻居/PPR索引，与显式谱 patch 路径不同。公开默认 `HeroFilter` 路径中的 `filter_bank` 是普通 tensor，未注册为 `nn.Parameter`；[train.py](../../reference_methods/HeroFilter/source/train.py) 的优化器仅接收 `model.parameters()`。此外，patch仅通过 top-k 索引选择特征，相关性权值未进入最终加权输出。这一快照不能直接作为“端到端可训练谱选邻域”的实现证据。

对 MIS 的可用结论是不要预设“高频越多越好”；v4 应按冲突、阻挡、释放机会区分状态，并测实际分支贡献。无需引入其全图谱相关矩阵和 top-p 搜索成本。

## COPT-MT / GCON：最直接的组合优化先例

COPT-MT 第3节以度数、聚类系数和三角形数作为节点输入，经 GCON 输出选中概率，再用约束解码得到集合；训练采用任务能量，多任务部分研究 MIS/MVC/MaxClique 等问题间的迁移。[COPT-MT正式页](https://proceedings.mlr.press/v306/canturk26a.html) · [GCON正式页](https://proceedings.mlr.press/v269/wenkel25a.html)

[gconconv.py](../../reference_methods/COPT-MT/source/src/models/layer/gconconv.py) 默认低通通道为传播阶数 `{0,1,2,4}`，差分通道为 `{0−1,1−2,2−4}`；每通道投影后进行局部注意力融合。多尺度差分与滤波器组用于 MIS 已有直接先例。RLNN 的具体差异是输入当前二值搜索状态、输出翻转概率、反复作用于搜索轨迹。v4 不能以“首次分频求解 MIS”为贡献，应证明任务状态条件注入优于同邻域、同参数的消息分支。

## Spectral-benchmark：测量网络整体频谱行为

论文第3–4节以跨频回归和频谱分桶产生的分类目标，测量 GNN 恢复不同频率信息的能力；非线性模块可以产生输入中缺失的频率分量，聚合算子的响应不足以描述整个网络。[正式论文页](https://proceedings.iclr.cc/paper_files/paper/2025/hash/a36c3dbe676fa8445715a31a90c66ab3-Abstract-Conference.html)

对应 [exploratory_study/main.py](../../reference_methods/Spectral-benchmark/source/src/exploratory_study/main.py) 的跨频信号与输出能量，以及 [main_benchmark/main.py](../../reference_methods/Spectral-benchmark/source/src/main_benchmark/main.py) 的 `get_cls_gts` 和分桶分类训练。其探索脚本以桶内特征向量均值构造代表方向；v4 可直接在小图上用完整正交特征基计算各通道投影能量，再按特征值区间求和，避免把代表方向投影等同于全部频带能量。

应分别观察原信号、MLP后分支、门控残差、融合表示和最终 logits，并结合置零分支后的解质量变化。这里只做频谱诊断，不把合成谱分类标签替代 MIS 收益监督。

## 补充方法与归档口径

MORGAN 的 [model.py](../../reference_methods/MORGAN/source/model.py) 将特征谱划为五组，专家处理特征向量，门控以各组特征值均值生成权重。该门控依赖图谱，不能直接解释为对当前 MIS 状态的动态响应。作者 README 标年与 [AAAI正式记录](https://ojs.aaai.org/index.php/AAAI/article/view/39553) 不一致，归档年份采用2026。

SLOG和S²GNN补充局部谱与远距离传播路线；FADC、FreqFusion、FDConv、F2Net补充分支职责、参数预算与梯度平衡思路。视觉代码的二维频域操作不应用于 `[N,K]` 的节点—轨迹张量。16个作者源码目录及已有许可均保留，上游快照未修改；下载源码不表示已训练复现。
