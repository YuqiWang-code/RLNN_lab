# RLNN 静态先验小试与 v1 方案

八维静态输入改善了候选入选频率预测。真实 MIS 小试里，MLP 的 0.5 秒点估计两次都为 +0.02，1.0 秒的优势随运行顺序改变，两档合并区间均跨零。固定 100 步下两组点估计均低于 B。部署继续使用 B 持续搜索和冻结 PAVE H1，下一版只验证低成本节点偏置能否在相同搜索步数下超过双常量校准。

## Mamba v0 逐图耗时

将同一图同一重复中的 Mamba 和 B 配对，先对每图五次差值取均值，再对 20 张图做 10,000 次配对 bootstrap。下表各阶段均为 Mamba 相对 B 的毫秒差，整图截止到 A.3 解码。

| 配置 | 采样精度 | 整图差及 95% CI（ms） | 准备及捕获差 | 回放差 | 超过 1.08× 的图 |
| --- | --- | ---: | ---: | ---: | ---: |
| 宽度 32，逐分量 | FP32 | +22.67 [20.10, 25.38] | +22.22 | +0.49 | 20/20 |
| 宽度 32，逐分量 | FP16 | +20.25 [17.54, 23.06] | +19.78 | +0.41 | 20/20 |
| 宽度 32，等价优化 | FP32 | +13.26 [10.84, 15.58] | +12.56 | +0.35 | 19/20 |
| 宽度 32，等价优化 | FP16 | +10.37 [7.91, 12.69] | +9.90 | +0.58 | 18/20 |
| 宽度 16，等价优化 | FP32 | +9.15 [6.67, 11.67] | +9.22 | +0.37 | 16/20 |
| 宽度 16，等价优化 | FP16 | +10.81 [7.44, 14.01] | +10.24 | +0.48 | 18/20 |

窄版 FP16 的图级中位差为 +11.95 ms，最慢的三张图各多 19.14–27.51 ms，准备及捕获占这三张图额外耗时的 95% 左右。FP32 与 FP16 的最慢图名单不同，均值差也分布在多数图上。零残差宽度 16 的两组 100 步配对中，A.3 大小各有 100/100 一致。优化宽度 32 的 FP16 运行里，PAVE 段恰好少 10.44 ms，而其输入大小在 99/100 次配对中相同，且另一精度的 PAVE 段反向增加。把 PAVE 段的单批时差计入总体，容易掩盖稳定的前处理成本。

零残差宽度 16 的预算测量中，0.5 秒平均少 51.7 步，20 图中少步数的有 14 张，差值区间 [−117.3, 18.3]。1.0 秒平均少 99.5 步，16 张图步数更少，区间 [−170.7, −23.6]。一次性先验的主要速度约束在每张新图进入回放之前。[逐图重算](../../../outputs/v7_context/analysis/static_prior_pilot/p0_reanalysis.json)

## 代理数据中的静态信息

20 张代理留出图的目标是冻结 B 多起点产生的优质候选中的节点入选频率，两半标签 Spearman 均值为 0.255。直接比较同容量 MLP 的局部输入版与八维输入版，可把输入信息的变化与 Mamba 算子的变化分开。

| 图级配对 | ΔAUC | 图级 95% CI | 胜 / 平 / 负 |
| --- | ---: | ---: | ---: |
| 八维 MLP − 局部 MLP | +0.00775 | [0.00058, 0.01578] | 13 / 0 / 7 |
| 八维 MSG − 局部 MLP | +0.00623 | [0.00201, 0.01055] | 15 / 0 / 5 |
| 八维 MSG − 八维 MLP | −0.00152 | [−0.00769, 0.00357] | 10 / 0 / 10 |
| Mamba − 八维 MLP | +0.00399 | [−0.00450, 0.01210] | 12 / 0 / 8 |
| Mamba − 八维 MSG | +0.00551 | [−0.00144, 0.01255] | 13 / 0 / 7 |

八维 MLP 的 Brier 相对局部版降低 0.000397，区间 [−0.000610, −0.000187]。这给静态特征的代理预测价值提供了两种度量下的同向证据。额外输入同时包含核数、BFS 距离、两跳覆盖、密度和图规模，单个特征的贡献尚未分离。原探针的线性可恢复性也存在差别，核数的留出 R² 为 0.604，BFS 距离仅 0.036。代理标签来自 B 的候选分布，因此最终判断看真实 MIS 搜索。

八维 MLP 去掉任意一张留出图后，ΔAUC 的均值仍在 +0.00552 到 +0.00895 之间。单图最大增益 +0.0500，使均值高于中位差 +0.00349，保留了正向但不均匀的图级分布。

## 真实 MIS 小试设置

参考种子 0、适配器训练种子 42，MLP 和 MSG 都使用八维特征、宽度 32、相同冻结 B。各用 256 张训练图、一个 epoch 和 512 次更新，特征归一化使用 1,000 张训练图的无标签图结构。训练后的 B 权重逐张量匹配，抽查的 20 条教师轨迹摘要相同。

评测取同一批前 50 张验证图，共用每图随机种子。FP32，K20，CUDA Graph 回放，固定 100 步同时记录 A.3 和 A.3＋冻结 PAVE。0.5/1.0 秒使用连续搜索与同一个 PAVE H1，预留 0.05 秒。固定工作量和 0.5 秒在 GPU 0，1.0 秒在 GPU 1，每个协议的三组均在同一张卡串行执行。限时复测保持权重、图集、GPU 和搜索种子，调换首末方法的执行顺序。合并限时结果时先在每图内对两轮差值取平均，再按 50 张图重采样。区间仅描述这批图的抽样波动，单个训练种子与两轮计时限定了结论范围。[运行脚本](../../../train_scripts/mamba/v0/pilot_static.sh)

## 训练后的偏置

在 20 张验证图的 B 轨迹上，取第 25、50、75 和 100 步的共同状态。对每个图分别将加入和移除偏置分解成节点均值与中心化节点分量。训练后的两组适配器已产生非零偏置，但节点分量引起的平均翻转概率变化约 0.00034。

| 方法 | 图内中心化偏置能量占比 | 完整偏置的平均绝对 Δp | 相对图内均值控制的平均绝对 Δp | 与 B 的前五翻转节点重合 |
| --- | ---: | ---: | ---: | ---: |
| MLP | 24.9% | 0.001046 | 0.000335 | 96.45% |
| MSG | 31.2% | 0.000996 | 0.000345 | 97.36% |

两组的图内均值分量占偏置二阶能量的多数，偏置对期望翻转数的平均变化为 MLP −0.055、MSG −0.094。该分解说明图级动作校准与节点排序需要独立控制。中心化分量能量和概率扰动提供诊断依据，实际 Size 贡献还需在同等搜索量下做干预。[逐图偏置诊断](../../../outputs/v7_context/static_prior_pilot/bias_diagnostics/run.json)

## 下一版方案

保留冻结 B、冻结 PAVE H1、一次性预计算和加入/移除两个偏置。主候选用廉价 MLP，八维 MLP 留作完整输入对照。MSG 留作既有同信息对照，Mamba 归档为当前速度和信息门槛的证据。

**将全局校准和节点排序拆开。** 先训练两个共享常量 `c_add` 和 `c_drop`，作为同样训练目标下的动作校准对照。结构臂输入对数度、邻居对数度均值和标准差、图密度、图规模这五项，采用 5→16→2 的 SiLU MLP，输出 `h_i = tanh(MLP(f_i))`。每个动作的缓存偏置如下。

```text
delta_i[a] = 0.25 * tanh(c[a]) + 0.125 * tanh(alpha) * (h_i[a] - mean_G(h[a]))
a ∈ {add, drop}
```

两个常量与门幅从零开始，MLP 读出按常规随机初始化。第二项在每图内均值为零，整项的绝对值上界为 0.5。静态量从度数和一次邻居矩聚合得到，每张图在采样前完成。采样中仅选取当前动作对应的偏置。固定比较 B、B＋双常量、B＋双常量和中心化 MLP。对同一训练后的结构权重再屏蔽中心化项，判断独立训练的容量差异与节点排序干预是否得出一致结论。

**匹配搜索量，再看同预算。** 首轮沿用 256 图和 512 次更新。用同图同随机数评测 T100，以及每十步解码并更新档案的等步数 T1000。T1000 的候选选择对齐持续搜索口径。限时评测在同卡按图交错三臂，同一个协议重复两次，记录实际步数、分段耗时、超时、P95 与可行率。把本轮未使用的后 50 张验证图作为新筛选组，配对区间按图重采样。

**继续投入的条件。** 廉价 MLP 的 T100 整图时间需达到 B 的 1.08× 以内。等步数 T1000 下，中心化结构臂对双常量的配对 ΔSize 需为正。0.5 秒加 PAVE 的两次点估计需都超过 B 和双常量，1.0 秒相对 B 的合并点估计需至少为 −0.02。通过小试才扩展至三种子和完整训练。进入 1,000 图作者测试前，要求 0.5 秒对 B 和双常量的图级配对区间下界均大于零，并锁定配置。
