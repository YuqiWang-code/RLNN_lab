# RLNN 静态先验 v2 · P1 oracle 方向训练结果

**No-go，但失败点已经定位到一行超参数。** 用 KaMIS 训练解做方向标签、门固定 `tanh(alpha)=0.5`、6,000 次更新后，注入方向与 KaMIS 标签的 cosine 只有 **−0.04**，top-20 重合 4.3%（随机基线 8%），四个协议全部未过效应门槛。原因不是编码器容量或信息不足，而是**对齐项只占总损失的 0.19%**（0.0078 对 3.30），编码器实际只拟合了 Erdős 项。

[P0 结果](RLNN_Mamba_v2_P0_Results.md) · [v1 复盘与 v2 方案](RLNN_Static_Prior_v1_Postmortem_and_v2_Plan.md) · [运行入口](../../train_scripts/mamba/v2/README.md)

## 训练

1,000 张训练图、3 epoch × 2,000 次更新、8 维特征、λ=0、学生混合 20%、`--static_node_limit 1.0`（对齐 P0 的 `oracle-kamis@0.5`）。全程 4.4 分钟。

| 轮次 | Erdős 损失 | 方向 MSE（×0.03 入模） | 节点偏置 RMS | 校验 T800 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 3.734 | 0.2347 → 0.0070 | 0.198 | 19.93 |
| 2 | 3.392 | 0.2615 → 0.0078 | 0.201 | 19.91 |
| 3 | 3.295 | 0.2596 → 0.0078 | 0.195 | 19.92 |

方向 MSE 从 0.235 **升到** 0.26，而 Erdős 损失从 3.73 降到 3.30：编码器把容量全部用在主目标上，对齐项被当成噪声忽略。加权后对齐项 0.0078，只占 Erdős 项的 **0.19%**。

## 评测

`--stage p1`，100 图 × 3 种子 × 2 次反序重复；空对照带按 P0 定义。

| 协议 | 中心化 ΔSize | 95% CI | 胜/平/负 | masked | matched-rand | 空对照带 | 判决 |
| --- | ---: | --- | --- | ---: | ---: | ---: | --- |
| T100 | −0.0133 | [−0.073, +0.047] | 22/54/24 | +0.0233 | +0.0200 | 0.170 | 未过 |
| T400 | +0.0400 | [+0.003, +0.080] | 17/76/7 | +0.0067 | −0.0167 | 0.150 | 未过 |
| T800 | −0.0033 | [−0.037, +0.030] | 9/83/8 | −0.0267 | −0.0167 | 0.070 | 未过 |
| 0.5 秒 | +0.0550 | [−0.020, +0.162] | 26/50/24 | +0.0750 | +0.0700 | 0.100 | 未过 |
| 1.0 秒 | +0.0050 | [−0.028, +0.035] | 12/80/8 | +0.0033 | +0.0033 | 0.050 | 未过 |

T400 的区间勉强排除零（+0.003），但远低于空对照带；**不能读成机制成立**。0.5 秒一档应打个折扣：`masked` 与 `null-rand` 的 Δ 都比 `centered` 大，说明该次运行噪声偏大（同图 B 只跑 19.712，P0 是 19.877，卡上另有任务），`speed` 门同时失败。

训练内部监控无异常：`flip_rate` 21.3–22.2 对 `base_flip_rate` 20.5–21.8，`divergence_t25/50/100` 0.09–0.12，`delta_prob_mean_abs` 0.0038（v1 是 9.8e-5）。也就是说**注入确实生效，只是方向不对**。

## 方向探针

`models/probe_direction_agreement.py`，100 图 × 3 种子，峰值 0.5，在同一组搜索种子上把"学到的方向"与 oracle 插值：

| λ | 0 | 0.25 | 0.5 | 0.75 | 1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Mean Size | 19.6167 | 19.7233 | 19.8500 | 19.9500 | 20.0133 |
| 相对 λ=0 | 0 | +0.107 | +0.233 | +0.333 | +0.397 |

两个端点都复现了 P0：λ=0 等于 B 的 19.617，λ=1 等于 P0 `oracle-kamis@0.5` 的 20.013。**曲线近似线性**，因此

```text
ΔSize(T100) ≈ 0.45 × cosine(学到的方向, oracle)
```

按此换算，要过 T100 的空对照带 0.17 需要 cosine ≳ 0.4；要过 0.5 秒的 0.10（oracle 自身只有 +0.19）需要 cosine ≳ 0.6。

一致性诊断（10 图）：

| 对比 | cosine |
| --- | ---: |
| 训练方向 vs KaMIS 标签 | −0.044 |
| 训练方向 vs v1 的节点方向 | −0.119 |

训练出的方向与**两者都无关**——既没有学到标签，也没有停留在 v1 的 Erdős 方向上。

## 本轮得到的三条硬信息

1. **失败原因是目标权重，不是信息或容量。** 对齐项占损失 0.19%，且 MSE 在训练中上升——这是"辅助项被主项压死"的典型特征。修法明确：让对齐项主导（`--oracle_weight` 提两个数量级，或把 Erdős 项权重降到 0），然后重测 cosine。单次迭代成本：训练 4 分钟 + 探针 1 分钟。
2. **剂量–反应曲线给出了方向质量的定价。** ΔSize 近似 0.45 × cosine，是后续迭代的直接目标函数，不必每次都跑完整评测。
3. **部署档的天花板很低。** same oracle 在 T100 值 +0.45、T800 +0.14、0.5 秒 +0.19、1.0 秒 +0.08。B 在 0.5 秒已接近本管线天花板，所以**静态方向先验的部署上限只有约 +0.19，且需要接近 oracle 的方向质量**。这条线真正的价值在低工作量区间（T25–T100：等价于把 T800 的收敛压到 T25），不在 0.5 秒。

## 权重判决实验（本轮补做）

P1 的对齐项只占总损失 0.19%，因此先验证"是不是权重把方向压死了"：同一配置只改 `--oracle_weight`。

| 配置 | Erdős 项 | 对齐项 | 加权后占比 | 方向 MSE | 节点 RMS | 编码器梯度 | hold-out cosine |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 权重 0.03（P1 原配置） | 3.73 → 3.30 | 0.235 → 0.260 | 0.19% | 0.260 | 0.195 | 0.22 | −0.044 |
| 权重 30 | 3.86 → 3.48 | 0.121 → 0.100 | 46% | 0.0997 | 0.035 | 1.21 → 0.46 | +0.047 |
| 权重 100（1 轮） | 3.87 | 0.121 | 76% | 0.1207 | 0.051 | 3.91 | +0.048 |

**权重提高 3,000 倍，hold-out cosine 从 −0.04 只动到 +0.05。** 所以权重不是瓶颈，方向本身没有学到。

样本内的方向 MSE 从 0.260 降到 0.100（相对"预测零"的 0.304，样本内 R² 达到 0.67），而同一检查点在留出图上 cosine 仍只有 0.05——**拟合的是训练图上的非泛化结构**。另一个次要缺陷：检查点按校验集 T100 的 A3 大小选取（该轮三个 epoch 是 19.55 / 19.46 / 19.50，选中的是第 1 轮），这个准则与"方向对不对齐"无关。

## 可达上限

v0 的代理探针给出过同信息对照的参照：8 维 MLP 在"优质解入选频率"标签上 held-out AUC 0.636（局部特征 0.628）。按 AUC 到相关系数的常规折算，对应的方向 cosine 大约在 0.2–0.25。代入实测的定价关系 ΔSize ≈ 0.45 × cosine：

| 方向质量 | T100 ΔSize | 0.5 秒 ΔSize | 是否过 T100 门槛（0.17） |
| --- | ---: | ---: | --- |
| oracle（cosine 1.0） | +0.45 | +0.19 | 过 |
| cosine 0.5 | +0.23 | +0.10 | 过（0.5 秒不过 0.10） |
| cosine 0.25（现有代理证据） | +0.11 | +0.05 | **不过** |
| cosine 0.05（本训练实测） | +0.02 | +0.01 | 不过 |

也就是说：**以 8 维静态特征现有的可预测性，这条路的期望收益约为 +0.11（T100）与 +0.05（0.5 秒），达不到预注册门槛 0.17 / 0.10。** 要过 0.5 秒那一档，需要 cosine ≳ 0.6——目前没有任何证据支持这个量级。

## 纯监督判决实验结果

按上一版的建议做了判决实验：Erdős 权重 0、λ=0、无 MDP、无学生混合；标签改成 **4 个独立种子优质解的入选频率**（`--train-oracle freq`，600 步 × 4 起点，取最大的一半解集）；损失改成**按正例加权的 BCE**；检查点按**留出 AUC** 选（900 图训练 / 100 图留出）。

| 项目 | 结果 |
| --- | --- |
| 可训练参数 | 178（8→16→2） |
| 留出 AUC（对频率标签） | **0.6375**（第 40 轮最优，仍在上升） |
| 留出 Spearman | 0.171 |
| 与 KaMIS 验证解的方向 cosine | **0.088** |
| top-20 节点重合（随机基线 8%） | **19.0%** |
| 秩相关 | 0.062 |
| **T100 直接搜索对照（100 图 × 3 种子）** | **+0.0033**，95% CI [−0.0567, +0.0633]，胜/平/负 = 36/227/37，21/100 张图有增益；B 19.620 对监督方向 19.623 |

三处缺陷都按设计修好了（MSE → BCE、单解 → 频率标签、按 T100 选点 → 按 AUC 选点），**结果仍然是零**。而且留出 AUC 0.6375 与 v0 代理探针的 0.636 几乎一致——说明这个监督拟合已经拿到了这 8 维特征所能提供的全部信息。

也就是说：**方向确实带着一点排序信号（top-20 重合是随机的 2.4 倍），但这点信号不足以推动搜索。** 按 `ΔSize ≈ 0.45 × cosine` 的外推是 +0.04，实测 +0.003，同一量级。

## 结论：不可达，建议归档

证据链已经闭合，四个环节各自独立地排除了：

1. **接口**（P0）：有杠杆，oracle 在 T100 值 +0.45、0.5 秒 +0.19；反向 oracle −0.29。接口不是瓶颈。
2. **算子**（v0）：MLP / MSG / Mamba 在代理任务上无差别（AUC 0.636 / 0.635 / 0.640）。算子不是瓶颈。
3. **优化目标**（v2 三次）：搜索目标训练（cosine −0.04）、加权到 46%/76% 主导（+0.05）、纯监督 + BCE + 频率标签 + AUC 选点（0.088）。目标不是瓶颈。
4. **输入信息**：剩下的就是瓶颈。8 维静态标量对"节点是否属于优质解"的可预测上限约 AUC 0.64，对应 cosine ≈0.1，对应 T100 ΔSize ≈0～+0.04，低于预注册门槛 0.17。

要在 0.5 秒那一档过线需要 cosine ≳ 0.6，按 AUC→cosine 的实测斜率大约要 AUC 0.85 以上。对"每节点 8 个静态标量"这个输入形态，不现实。

### 建议的收尾

1. **归档这条线**，保留三样东西：P0 的接口杠杆与定价曲线（`ΔSize ≈ 0.45 × cosine`，以及部署档天花板 +0.19）、三次训练失败的各自原因、以及"瓶颈在输入信息"这一条结论。这本身是一份完整的实证负结果。
2. 部署继续用 **B 持续搜索 + 冻结 PAVE-Stats H1**，不动。
3. 部署收益的争取转回**盆地逃逸**（v3 记录 KaMIS 的 +0.55 在局部邻域之外，48/52 张被改善的图没有当前后备动作）。
4. 若将来仍想做"一次性静态先验"，前提是换输入形态——不是换算子、不是换损失、不是调幅度。可行方向：把 8 个标量换成真正的子图结构表示（多跳指纹、社区分割、求解器轨迹的归纳偏置），或者让静态编码器直接算子图级打分而不是节点级排序。

- `models/train_static_direction.py`：纯监督方向拟合（频率标签、加权 BCE、按 AUC 选点），写出的检查点可被 `preflight_policy` 直接加载。
