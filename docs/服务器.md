## 环境

专用环境位于 `/home/hzeng/envs/nexco`，配置为 [models/environment-5090.yml](../models/environment-5090.yml)。Python 3.10.19、PyTorch 2.9.1+cu130、NumPy 1.26.4、Lightning 1.9.5、TorchMetrics 0.11.4、PyG 2.7.0、torch-scatter 2.1.2+pt29cu130、torch-sparse 0.6.18+pt29cu130、Cython 3.0.12、W&B 0.23.1。

RTX 5090 的 CUDA 矩阵计算及 TSP100 GNN 前向反向均已通过，batch size=12 的前向反向峰值显存约 18,010 MiB。Cython 路径合并扩展及 CVRP C++ 本地搜索已在此环境编译。完整包列表保存于 `outputs/v001_tsp100/setup/requirements.txt`。

激活命令：`source /home/hzeng/miniconda3/bin/activate /home/hzeng/envs/nexco`。独立创建环境可运行 `conda env create -f models/environment-5090.yml`，随后在 `models/diffusion/utils/cython_merge/` 执行 `python setup.py build_ext --inplace`，在 `models/diffusion/utils/local_search/c_classic/` 执行 `make`。

`models/environment.yml` 保存原始 Python 3.7 / PyTorch 1.11 + CUDA 11.3 配置。RTX 5090 使用上述专用配置。PyTorch 的 Blackwell 支持说明见 [官方发布说明](https://pytorch.org/blog/pytorch-2-7/)。
