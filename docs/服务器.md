## Linux 待验证环境

原始 `models/environment.yml` 是 Python 3.8 / PyTorch 2.4.1 / CUDA 12.4，并含 cu121 扩展，保留作来源记录。RTX 5090 使用单独环境：Python 3.11、PyTorch 2.7.1 cu128、匹配 pt27/cu128 的 torch-scatter、PyG 2.6.1、Accelerate 1.0.1、NetworkX 2.8.8。此方案尚未创建和验证。

[PyTorch 2.7 发布说明](https://pytorch.org/blog/pytorch-2-7/)列出 Blackwell 与 CUDA 12.8 支持；[PyG 安装说明](https://pytorch-geometric.readthedocs.io/en/latest/install/installation.html)列出 torch 2.7.* / cu128 扩展索引。应通过真实 sparse CSR、scatter、GCN 前向、反向与解码冒烟确认组合可用，再保存 `pip freeze`。

部署后在 Linux 项目根目录执行：

```bash
python3.11 -m venv "$HOME/envs/rlnn"
source "$HOME/envs/rlnn/bin/activate"
bash train_scripts/v000_rlnn_baseline/setup_env.sh
CUDA_VISIBLE_DEVICES=1 RUN_NAME=smoke_001 bash train_scripts/v000_rlnn_baseline/smoke.sh
```
