## 环境

账户中已有 `/home/hzeng/envs/MASKCO_env`、`/home/hzeng/miniconda3/envs/MASKCO_env`、`ZH`、`model_reproduction_5090` 等环境，尚未建立本项目专用 `nexco` 环境。Conda base 的 Python 为 3.13.12。

`models/environment.yml` 记录了 Python 3.7、PyTorch 1.11.0+cu113、Lightning 1.7.7 的原始环境，不能直接作为本机 RTX 5090 的可用环境结论。PyTorch 从 2.7 起发布支持 Blackwell 的 CUDA 12.8 构建，见 [官方发布说明](https://pytorch.org/blog/pytorch-2-7/)。本项目依赖 Lightning 1.x 的 `test_epoch_end` 等接口，适配新 PyTorch 时需同时确认 Lightning 和 PyG 扩展，完成小规模训练、验证、测试后再固定版本。
