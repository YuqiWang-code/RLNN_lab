## Linux 已验证环境

原始 `models/environment.yml` 是 Python 3.8 / PyTorch 2.4.1 / CUDA 12.4，并含 cu121 扩展，保留作来源记录。RTX 5090 使用单独环境：Python 3.10、PyTorch 2.9.1 cu130、匹配 pt29/cu130 的 torch-scatter、PyG 2.7.0、Accelerate 1.0.1、NetworkX 2.8.8。该组合已通过 GPU 训练、checkpoint 加载、解码及 fp16 推理冒烟；精确依赖见 `outputs/v000_rlnn_baseline/setup/requirements.txt`。

[PyTorch 2.7 发布说明](https://pytorch.org/blog/pytorch-2-7/)列出 Blackwell 与 CUDA 12.8 支持；[PyG 安装说明](https://pytorch-geometric.readthedocs.io/en/latest/install/installation.html)列出按 PyTorch/CUDA 组合选择扩展的规则。实际使用 pt29/cu130 的扩展，CSR、scatter、GCN 前向/反向和解码均已通过。

部署后在 Linux 项目根目录执行：

```bash
python3.10 -m venv "$HOME/envs/rlnn"
source "$HOME/envs/rlnn/bin/activate"
bash train_scripts/legacy/v000_rlnn_baseline/setup_env.sh
CUDA_VISIBLE_DEVICES=1 RUN_NAME=smoke_001 bash train_scripts/legacy/v000_rlnn_baseline/smoke.sh
```

Windows 本地仅进行整理：`python tools/server.py status`、`python tools/server.py pull`、`node tools/collect_results.mjs`。本地工具依赖见 [tools/README.md](../tools/README.md)。大数据与权重留在服务器。
