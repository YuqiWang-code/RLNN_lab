# 数据集

默认任务为最大独立集 MIS，图规模 RB200–300。源码来自 RLD4CO ZIP 的 `models/data/rb_generator.py`、`xu_util.py`。作者提供的[测试数据](https://huggingface.co/datasets/shengyuf/RLD4CO)适合后续与论文比较，本次未下载。

## 本项目划分

| 划分 | 默认路径 | 数量 | 生成 seed |
| --- | --- | --- | --- |
| train | `models/data/MIS/RB_small_train` | 1000 | 0 |
| val | `models/data/MIS/RB_small_val` | 100 | 100000 |
| test | `models/data/MIS/RB_small_test` | 500 | 200000 |

当前三组均已生成，实际数量为 1000/100/500。官方 small 生成器在本批数据中的实际节点数范围均为 200–264；完整统计见[数据清单](../outputs/v000_rlnn_baseline/data/manifest.json)。本次生成使用 4 个 CPU 进程。数据留在服务器，本地只保留清单。生成器每图使用 `seed+idx`，上述区间不重叠。Linux 项目根目录执行 `bash train_scripts/v000_rlnn_baseline/prepare_data.sh`，默认单进程，可通过 `DATA_ROOT`、`TRAIN_COUNT`、`VALID_COUNT`、`TEST_COUNT`、`PROCESSES` 配置；已有划分目录会拒绝覆盖。改变数量后须记录实际数量。本地生成测试集不等同作者测试集；作者 README 说明论文 RB/BA 数字平均两个 500 图组。

生成器构造 RB 图、删除孤立点、拒绝不在 200–300 节点范围内的样本，保存 NetworkX Graph 的 pickle（`.gpickle`）。`xu_util.get_random_instance(size='small')` 对应实际分布。该生成器内部固定 small，不以简单放大节点范围的方式生成大规模图。

## 加载与评价

`models/problems/mis.py::Dataset` 使用 `glob('*gpickle')` 和 `nx.read_gpickle`，转为 PyG 图，补无向边、去自环；每条有向边权重为 1/2，`b=-1`。训练不需要最优标签、参考目标值或额外节点特征。使用 NetworkX 2.8.8 保留 `read_gpickle` API；图文件来自本项目或可信数据源。

`num_samples>0` 取 glob 返回的前 N 个文件，未排序。默认生成恰好指定数量并完整使用，避免截断顺序影响选样；后续更换数据集须记录实际选样。运行元数据记录路径、可用数量、样本上限、种子与配置。

暂未准备可靠参考解，不计算 gap，也不称参考求解器结果为已知最优。MIS 可行解独立集大小越大越好；原始负目标与解码口径见[基线说明](RLNN基线.md)。

冒烟使用 8 节点 ER 图，train/val/test 分别 2/1/1，种子为 0、1 / 100 / 200，仅验证执行链路，不能作为 RB 或论文成绩。

## 张量缓存

原始图已预转换到服务器 `models/data/MIS_tensors/`，数量仍为 1000/100/500。manifest 保留原文件顺序；缓存边索引与原加载输出对照一致。默认启动器使用缓存，原始 GPickle 保留。准备方式与测量见[数据读取性能](数据读取性能.md)。
