## 格式

- TSP：二维坐标序列，随后为 ` output ` 和从 1 开始的闭合路径节点编号。加载器将编号转成从 0 开始。
- CVRP：`depots ... points ... demands ... capacity ... output ...`，路径以 0 表示仓库，加载器会在首个 -1 处截断。
- MIS：NetworkX `.gpickle` 图；标签来自图节点的 `label` 属性，或同名 `_unweighted.result` 文本文件。

## TSP100 训练与验证

`v001_tsp100` 使用服务器独立生成的数据，生成器为 [models/generate_tsp_data.py](../models/generate_tsp_data.py)。坐标为 100 个独立均匀分布于 `[0,1]^2` 的点，使用 `numpy.random.SeedSequence([seed, index])` 初始化每个实例的随机数生成器。生成环境 NumPy 版本为 2.2.6。

| 划分 | 服务器上相对 models 的路径 | 实例数 | 种子 | 参考路径平均长度 |
| --- | --- | ---: | ---: | ---: |
| 训练 | `data/tsp_train/tsp100_train_lkh100_10000.txt` | 10000 | 20261106 | 7.765640398073105 |
| 验证 | `data/tsp/tsp100_val_lkh100_128.txt` | 128 | 20261107 | 7.781792605215850 |
| 测试 | `data/tsp_test/tsp100_concorde_7.75585.txt` | 1280 | 上游固定测试集 | 文件名标记 7.75585 |

训练和验证标签由 `/usr/local/bin/LKH`（LKH 3.0.14）生成，RUNS=1、MAX_TRIALS=100、EUC_2D，坐标缩放为 1,000,000 后取整。保存的坐标保留原始连续值，路径长度在这些坐标上计算。每条标签均检查为所有节点的一次排列，并追加起点形成闭合回路。

数据生成配置及统计保存在 [训练清单](../outputs/v001_tsp100/data/train_manifest.json)和 [验证清单](../outputs/v001_tsp100/data/val_manifest.json)。[训练数据](../models/data/tsp_train/tsp100_train_lkh100_10000.txt)为 31.48 MiB，[验证数据](../models/data/tsp/tsp100_val_lkh100_128.txt)为 0.40 MiB，均同步到本地与 Git。训练、验证独立生成，测试沿用固定的 Concorde 数据；测试数据不参与训练与模型选择。上游 TSP 数据来源可参见 [DIFUSCO 数据说明](https://github.com/Edward-Sun/DIFUSCO/blob/main/data/README.md)和 [learning-tsp](https://github.com/chaitjo/learning-tsp)。
