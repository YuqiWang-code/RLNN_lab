## 神经组合优化

| 文献 | 来源 | 用途 |
| --- | --- | --- |
| [Regularized Langevin Dynamics for Combinatorial Optimization](神经组合优化/RLNN%28ICML2025%29.pdf) | Shengyu Feng, Yiming Yang；ICML 2025，PMLR 267:16977–16992；[正式页](https://proceedings.mlr.press/v267/feng25r.html) | 当前核心基线，研究 RLNN / erdoes |

RLD 通过约束期望翻转距离改善离散搜索；RLNN 以残差 GCN 预测翻转概率，erdoes 路径利用可微目标与距离正则训练。RLSA 与 reinforce 路径作为上游能力保留。

PDF 实际标题、作者与正式论文页一致，原文件内容保留。[官方代码](https://github.com/Shengyu-Feng/RLD4CO)的本地来源见[源码记录](../源码来源.md)。复现重点是 5 层 / 128 维、训练粒子数、状态 batch、多卡与单卡更新预算、可行解解码；差异统一记录在 [RLNN基线](../RLNN基线.md)。
