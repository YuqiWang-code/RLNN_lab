# TSP100 基线

`v001_tsp100` 使用 10,000 个 LKH 标注实例训练一轮，在全部 1,280 个固定 Concorde 测试实例上，扩展后平均路径长度为 **7.834235**，平均 gap 为 **1.0085%**。模型为 12 层、隐藏维度 256 的 GNN，共 4,888,066 个可训练参数。训练、验证与测试分别使用独立划分。

## 训练

| 设置 | 数值 |
| --- | --- |
| 随机种子 | 1234 |
| 训练 / 验证实例数 | 10000 / 128 |
| batch size / epoch | 12 / 1 |
| 实际优化步数 | 833 |
| 优化器 | AdamW |
| 初始学习率 / weight decay | 0.001 / 0.0001 |
| 调度 | CosineAnnealingLR，833 步 |
| 训练精度 / GPU | FP32 / RTX 5090 GPU 1 |
| 一致性 alpha | 0.5 |
| epoch 平均训练损失 | 0.08615902811288834 |
| 最后记录的 batch 损失（step=799） | 0.02831217274069786 |

训练集以 batch size=12、`drop_last=True` 使用，共 9,996 个实例参与本轮更新。模型从零初始化，参考路径由 LKH 生成，RUNS=1、MAX_TRIALS=100。数据来源、坐标分布和生成种子见 [数据集](数据集.md)。

测试加载训练所得 `epoch=0-step=833.ckpt`，seed=1234，单卡 FP32，parallel_sampling=1、sequential_sampling=1，rewrite_steps=5、rewrite_iterations=5、rewrite_ratio=0.1、m1=0.9、m2=0.7，2-opt 上限为 5,000 次，在无改进时提前停止。每个实例共进行 31 次网络前向，包含初始构建及后续扩展。

gap 按每个实例的相对参考路径误差计算后取均值。耗时包含该实例的网络推理、路径合并、扩展及 2-opt，不含模型加载。显存来自 PyTorch allocated memory；峰值每个实例重置后记录，再对实例取均值，不含 CUDA 缓存预留显存。
