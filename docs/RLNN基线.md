# RLNN 基线

当前版本 `v000_rlnn_baseline`，MIS RB200–300，单张 RTX 5090（GPU 1）。研究 RLNN / erdoes。当前训练采用多图合批，重点控制 GPU 显存占用。

## 当前配置

| 参数 | 取值 |
| --- | --- |
| 网络 | 5 层残差 GCN，隐藏维 128 |
| 训练 | 50 epoch，Adam lr 0.0001，float32 |
| 图 batch | 13 图，最后一批 12 图 |
| 状态 batch | 配置 1024，每图实际 1000 状态 |
| 一次更新状态数 | 通常 13000，最后一批 12000 |
| 训练采样 | 每图 K=20、T′=50 |
| 推理采样 | 每图 K=20、T=100，fp16 |
| 正则 | d=5、β=1.02、λ=0.5 |
| 数据 | train/val/test 1000/100/500 |
| 更新预算 | 每 epoch 77 次，50 epoch 共 3850 次 |
| 显存分配器 | cudaMallocAsync |

启动入口 `train_scripts/v000_rlnn_baseline/train.sh`，可用 `GRAPH_BATCH_SIZE`、`BATCH_SIZE` 覆盖批大小。当前运行 `rb_train_g13_cache_w8_gpu1_seed0`，使用张量缓存与 8 个常驻 worker，从第 22 轮最佳权重继续至总第 50 轮，训练后独立测试。该起点 Adam 与随机状态缺失并重置，详见[数据读取性能与续训协议](数据读取性能.md)。

## 合批实现

DataLoader 每次返回多张图，通过上游 build_batch 构建块对角图，图之间没有边。GCN 同时预测各图的翻转概率，轨迹也在块图中并行生成；每图仍保留 20 条轨迹、50 步，得到各自的 1000 个训练状态。

训练能量按图取平均，距离正则先按图汇总翻转概率再取平均，避免将 13 张图错误地视作一个距离目标。合并图前向、标量损失和参数梯度已与逐图平均计算对照通过。单图分支保留上游流程。

最大图组合压力测试使用 13 张各 264 节点的图，整卡占用约 75%；代表性批次约 65%。使用 cudaMallocAsync 控制变动图尺寸下的缓存碎片。实际占用会随图尺寸及其他进程变化，不固定在某个百分比。原始测量见[显存与性能](Batch性能.md)。

## 指标与来源

MIS 能量为 `β∑(u,v)∈E x_u x_v − ∑u x_u`。erdoes 对软翻转后的能量加距离正则；日志 loss 是 0.95/0.05 指数平滑值。默认贪心解码返回负独立集大小，raw_obj 越小对应独立集越大，派生 independent_set_size=-raw_obj。

val/test time 是上游每图采样与解码平均墙钟秒数，未显式 CUDA 同步；run/wall_time 为运行器子进程阶段墙钟时间，包含完整训练、验证或测试。GPU 内存与吞吐短测显式同步，与正式计时分别记录。当前多图分支 Iteration 为累计优化器更新次数，导入工作簿 step 字段；原始单图分支不提供可靠步数。

训练、测试命令与配置保存在 run.json，原始日志、CSV 留在对应运行目录。权重与图数据留在服务器。性能测量用 benchmark/ 前缀，集成检查写入冒烟工作簿，均不作为完整测试成绩。

## 已知差异

论文每 GPU 状态 batch 为 32，官方脚本为 64。本项目使用多图大 batch，更新次数与论文不同，不称为严格论文复现。论文训练 K′=10，ZIP generate_data 实际使用 K=20，num_kp 仍未参与采样。每图采样预算保持 ZIP 行为，未随合批增大。

原基线在本项目独立生成的测试集上使用 ZIP 贪心构造。作者公开测试集上的贪心构造与附录 A.3 梯度翻转对照见[实验报告](实验报告.md)。无可靠最优参考，不计算 gap。旧 batch 32 与单图 batch 1024 运行已标记 stopped，不能作为完整成绩。

上游 prepare 的 optimzier 拼写与 RLPGSA 未定义分支保留原状；本项目使用单进程、float32 训练和 RLNN / erdoes。

GPU 环境、RB 数据、端到端冒烟、50 epoch 正式训练与 500 图测试均已完成，结果见[实验报告](实验报告.md)。
