# RLNN Lab 项目现状

更新于 2026-11-18。项目基于 RLD4CO，研究 RB200–300 图的最大独立集。正式限时对照使用 1000 张作者测试图。本地生成的训练、验证、测试集分别为 1000、100、500 张。 [数据集](数据集.md) · [源码来源](源码来源.md)

## 论文命名

当前论文标题为 *SPRINT: Feasible-Set-First Neural Search for Maximum Independent Set Under a 200-Millisecond Deadline*。求解器族 **SPRINT** 含两条路线：构造路线 **SPRINT-C**（可行集搜索：先发布贪心极大集，再用学习或度数排序做交换与团分支）与投机路线 **SPRINT-S**（GPU 粒子搜索：CUDA Graph 重放、中点与末尾 A.3 解码）。旧文档里的“融合 RLNN / Fused RLNN”对应 SPRINT-S 的执行协议；旧表 1 的 “Fused RLNN (Ours)” 行现记为 “SPRINT-C (learned)”。

## 边界与未决事项

- **外部基线。** 0.2 秒已有内部同预算配对，RLSA 仍为近似墙钟的固定步数参照。1 秒比较使用 RLSA 插值。当前证据支持 RB200–300 上的配置内提升，可比对外结论以这些计时协议为限。
- **引擎验收。** 固定 130 步的 200 图探针中，编译与未编译有 194 图的 SIZE 相同，最大绝对差 1，均值漂移 −0.010。端到端速度比 1.43× 达到倍率指标，0.637 ms/步高于 0.59 ms/步指标。原数值验收协议还要求 1000 图、三个种子的同步数对照。 [融合复审](temporary/RLNN_v13_Review.md) · [验收协议](temporary/RLNN_v13_Engine_Rewrite_Spec.md)
- **排序权重（v17）。** 200 ms 同一批内比较仅度数、λ=0.1/0.25/1.0 与仅学习五个臂：大型 RB 42.4387–42.5130、小型 ER 44.1432–44.4245、小型 RB 五臂同为 20.1150；相对同批度数臂的差值为 +0.02–+0.07（大 RB）与 −0.11–+0.17（小 ER），大 ER 的 16 图区间都含零。混合排序与 −度数 的 Spearman 相关 0.99 以上，学习分数本身 0.58–0.96。 [逐图记录](../outputs/v17/priority_mix_20261122/) · [运行说明](../outputs/v17/priority_mix_20261122/README.md)
- **闭包诊断。** 在测试配置上，PAVE 余量随输入变强而收缩。1 秒档存在少量正缺口，量级接近零。按图预测是否启用 PAVE 仍为待验证方案。 [研究备忘](temporary/RLNN_v12_SecondContribution.md)
- **历史启动器。** v3 价值头训练、Mamba、结构补偿及 v7 的部分脚本引用归档前的源码路径。复跑这些记录时使用对应历史提交的整套代码与脚本。上游 MaxCut 的 GPickle 分支缺少导入，RLPGSA 分支引用未定义求解器。 [归档源码](../models/closed/README.md) · [历史记录](已归档的想法和文件/README.md)
