# 常驻 MIS 求解器的限时交付

## 计时口径

学习排序、度排序和 OnlineMIS 从同一份主机端边列表开始。计时包括构造图表示、搜索、复制可行解到主机档案，以及学习臂的 GPU 打分和数据往返。OnlineMIS 原生搜索在首个贪心解和自身最优更新点发布节点集。原命令行版本在进程退出后读取当时的解。两种接口所得差异同时包含进程成本和提前读取解的影响。

每个预算独立求解，均预留 3 ms 用于返回。两个 RB 调度按原 200 ms 配置等比缩放团分支时间，小 ER 始终进行交换。每次仅占一个 CPU 核，学习臂另用一张 RTX 5090。合法解在预算内已复制到主机即可计分，未交付记零；求解调用是否在预算内结束单独统计。全部节点见证均按原边表核验。[实验入口](../train_scripts/v16/README.md) · [逐图记录](../outputs/v16/anytime_author/) · [统计与制图](../tools/summarize_resident_deadlines.py)

## ER 同核交错复测

分批运行时，度排序在 50 和 100 ms 的平均搜索步数为 47,807 和 28,255。将全部 128 张 ER 图的 12 个方法–预算组合放入同一进程、同一 CPU 物理核，在各图与种子内平衡轮转后，两档平均步数为 15,195 和 31,484，100 ms 的 SIZE 高 0.2266 [0.1745, 0.2839]。全部 4,608 次均按时交付可行解。200 ms 时，学习排序、度排序和常驻 OnlineMIS 的 SIZE 为 44.3281、44.2760、42.7083。学习排序对常驻 OnlineMIS 高 1.6198 [1.5156, 1.7214]，对度排序高 0.0521 [−0.0365, 0.1406]。学习相对度排序的四个区间均跨零。[四预算汇总](../outputs/v16/er_interleaved/summary.csv) · [图级配对](../outputs/v16/er_interleaved/paired.csv)

## 独立图族

DIMACS COLOR 目录中标记为 REG 的全部 14 张寄存器分配干涉图均纳入，来自四个程序，含 184–864 个顶点，每张保留 10–345 个孤点。各臂固定三个种子、200 ms。学习臂沿用原检查点，两个优先级臂统一使用 ER 的纯交换调度。训练和选择调度时均未使用这些图。[实例目录](https://mat.tepper.cmu.edu/COLOR/instances.html) · [原始文件](https://archive.dimacs.rutgers.edu/pub/challenge/graph/benchmarks/color/)

| 方法 | 首解平均 SIZE | 最终平均 SIZE | 首达最优中位数 | 平均返回 | 按时返回并达到最优 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 学习排序 | 208.3571 | 208.3571 | 0.54 ms | 197.03 ms | 42/42 |
| 度排序 | 208.3571 | 208.3571 | 0.96 ms | 197.04 ms | 42/42 |
| 常驻 OnlineMIS | 178.0476 | 208.3571 | 1.48 ms | 169.33 ms | 42/42 |

每张图都能构造一组互不相交且覆盖全部顶点的团，团数等于实验返回的独立集大小，因而可离线证明最优。两个优先级臂的首解在打分前由同一段贪心代码构造，42 次均已最优。OnlineMIS 在每次运行中都改进了首解并追平。冻结配置能迁移到这组实际冲突图。首解已达全局最优，后续排序没有额外提高 SIZE 的空间。[逐图结果](../outputs/v16/dimacs_register/by_graph.csv) · [最优性证书](../outputs/v16/dimacs_register/clique_covers.json)
