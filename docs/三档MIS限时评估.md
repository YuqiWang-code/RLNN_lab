# 三档 MIS 的 200 ms 评估

## 200 ms 正式结果

2,128 张作者图分别运行种子 1017、1019、1021。新版使用一个 CPU 核与一张 RTX 5090，三档共享权重。6,384 次都交付了合法独立集，求解阶段的实际返回时间也都在 200 ms 内。表中选取各档实测均值最高的外部对照，括号内为对该方法的图级配对差及 95% 区间。[逐图节点集与计时](../outputs/v15/priority_200ms_20261121/test/) · [正式配对表](../outputs/v15/priority_200ms_20261121/formal_comparison.csv)

| 作者图集 | 原融合 SIZE | 新版 SIZE | 平均返回 | 最强已测外部对照 | 新版相对增益 [95% CI] |
|---|---:|---:|---:|---|---:|
| RB-[200–300] | 20.0300 | **20.1150** | 9.81 ms | OnlineMIS 20.0393 | +0.0757 [0.0557, 0.1000] |
| RB-[800–1200] | 28.9847 | **42.4803** | 136.64 ms | 调时 OnlineMIS 41.6140 | +0.8663 [0.8033, 0.9547] |
| ER-[700–800] | 40.8854 | **44.3620** | 197.07 ms | RLSA 43.1536 | +1.2083 [0.9818, 1.5547] |

大 RB 的 OnlineMIS 对照将内部搜索时限从 180 ms 调为独立验证选择的 120 ms，留出进程返回与收集解的时间。正式集均值提高到 41.6140，超过旧表的 FLD-EG 重现值 35.3673。三档均保留这次复跑和旧配置，完整统计同时给出两者。[OnlineMIS 时限选择与正式运行](../outputs/v15/priority_mis_20261121/online_mis_tuned/)

### 单独估计学习排序的贡献

三臂共享初始合法集、时间预算、分支与交换规则。纯度排序只按负顶点度给后续搜索排序，无优先排序把这些分数置零。首个可行解由动态最小剩余度贪心交付。对两个 RB 图集，纯度排序分别得到 20.1150 和 42.4717；学习版相对它的增益分别为 0 和 +0.0087 [−0.0063, 0.0237]。小 ER 上，学习版相对无优先排序提高 +0.1693 [0.0729, 0.2578]，相对纯度排序提高 +0.0807 [−0.0026, 0.1641]。与外部基线的大幅差距来自整套配置，可行解搜索本身已经贡献了大部分提升。[全部排序对照](../outputs/v15/priority_200ms_20261121/formal_comparison.csv)

## 重训后的 Fused RLNN

原融合引擎从 200 个二值粒子中挑选低能量状态，再解码为独立集。新配置先按最小剩余度构造一个极大独立集并交付到主机，随后利用同一五层 GCN 对每个顶点打一次分。对三个分布均采用图内标准化的负度，加上 0.25 倍图内标准化的神经分数。CPU 搜索用这一顺序选择扩展或交换的顶点。输入转换、GPU 往返、打分和保存每个新解均占用逐图的 200 ms。每个存档集合在原图上检查独立性。[网络](../models/scale_priority.py) · [限时推理](../models/eval_priority_search.py)

在 RB 图上，解码器按邻域相似度尝试合并团，并通过邻接关系逐次确认合并后的顶点两两相连。独立集在每个团里最多选一个顶点，剩余非空团数因此给出搜索上界。小 RB 先分配最多 185 ms 给分支搜索，证明最优即可提前返回；大 RB 先运行可行集交换，再给团分支预留末段 175 ms。小 ER 直接使用可行集交换。三条路线均在独立验证图上确定，预留 3 ms 返回。[团分支实现](../models/mis_clique_refine.cpp) · [交换解码器](../models/priority_search.cpp) · [三档启动器](../train_scripts/v15/priority_200ms.sh)

训练从原融合版的 GCN 权重初始化，为隐藏表示和 5 个节点特征增加线性残差读出，同时更新骨干。训练集每档 128 张图，验证集每档 16 张图。每图用 OnlineMIS 的 8 个种子生成合法解，以最大的 4 个解中各顶点的入选频率做软标签。第一套联合训练运行 24 轮，第 1 轮的共享权重入选；另一套以负度为初值的残差模型在验证上选中第 0 轮。该版本使用启发式求解器提供训练监督。[冻结权重](../outputs/v11/scale_priority_20261121/training/best.pt) · [训练配置](../outputs/v11/scale_priority_20261121/training/config.json) · [逐轮验证](../outputs/v11/scale_priority_20261121/training/epochs.csv)

## 小 RB 的最优值

对 1,000 张作者 RB-[200–300] 测试图另行核实全局最优值。先逐边验证一个覆盖全部顶点的不相交团划分。375 张图上，团数直接等于已交付的独立集大小；其余 625 张用 CaDiCaL 检查“至少多一个顶点”这一命题，均不可满足。全套最优均值为 **20.1150**。学习版三个种子的全部 3,000 个按时解均达到对应最优值。求解器在原 200 ms 窗口内已有 2,981 次同时得到相等的上下界；离线核验只用于判定已交付解的质量。[逐图最优值](../outputs/v15/priority_200ms_20261121/offline_optimality/RB_small/optima.csv) · [SAT 核验脚本](../tools/verify_rb_optima.py)

## 验证和计分

三档各自生成 16 张验证图。训练图起始种子为 4,100,000，验证图起始种子为 4,200,000，三个分布依表顺序附加 0、10,000、20,000，再加图编号。验证用于确定模型与搜索参数。冻结配置后对整套作者测试图运行 1017、1019、1021 三个搜索种子，共 6,384 个图–种子对。

为给单线程 OnlineMIS 的进程开销留出时间，外层固定 200 ms，仅在独立验证图上以搜索种子 517 比较三档内部时限。取验证 SIZE 最大的配置，同分取较长内部时限。每个分布独占一个物理核。下表给出验证 SIZE 和冻结选择。 [运行入口](../train_scripts/v15/eval_online_mis.sh)

| 分布 | 内部 120 ms | 内部 150 ms | 内部 180 ms | 正式内部时限 |
|---|---:|---:|---:|---:|
| RB-[200–300] | 19.9375 | 19.9375 | 19.9375 | 180 ms |
| RB-[800–1200] | 41.0000 | 35.5000 | 15.3750 | 120 ms |
| ER-[700–800] | 42.4375 | 37.2500 | 13.2500 | 120 ms |
| ER-[9000–11000] | 0.0000 | 0.0000 | 0.0000 | 180 ms |

万节点 ER 的 CLI 对照使用 16 张独立的验证图。顶点数从 9,000 到 11,000 的整数中均匀抽取，边独立生成，概率为 0.02，图种子为 4,230,000–4,230,015。三个内部时限的验证 SIZE 均为 0，按同分规则选定 180 ms。在 16 张作者测试图、三个固定搜索种子上，CLI 的 48 次调用均于读取解文件前超时，平均返回时间 206.15 ms，按时 SIZE 为 0。复跑依次执行 `bash train_scripts/v15/eval_online_mis.sh validation ER_large 24` 和 `bash train_scripts/v15/eval_online_mis.sh test ER_large 24`。[验证时限和分数](../outputs/v15/priority_mis_20261121/online_mis_tuned/validation/ER_large/selection.json) · [逐图测试记录](../outputs/v15/priority_mis_20261121/online_mis_tuned/test/ER_large/per_graph.csv)

正式计分分别比较原表冠军及独立验证选定的 OnlineMIS。对每张图先平均三个种子的 SIZE 差，再按图有放回重采样 5,000 次，报告各分布单独的 95% 百分位区间。每档分别给出按时数、实际平均及 P95 墙钟和胜平负。学习贡献使用学习版与无学习版的直接配对差。 [逐图计分入口](../tools/score_priority_mis.py)
